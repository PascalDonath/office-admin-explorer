This window is a training mock of Word for Microsoft 365 Apps admins. Every i marks an element with admin information: idMso, Policy ID, Group Policy, registry value, Intune setting and links.

Good first stops

  • File › Account › Update Options: update policies, channel GUIDs, update history

Trusted Documents

Warning: Trusted Documents open without any security prompts for macros, ActiveX controls and other types of active content in the document, and the document no longer opens in Protected View or Application Guard. For a Trusted Document, you won't be prompted the next time you open the document even if new active content was added to the document or changes were made to existing active content. Therefore, you should only trust documents if you trust their source. Exception: If an IT administrator blocks active content by setting a policy, or you set a Trust Center setting that blocks active content, the active content stays blocked.
