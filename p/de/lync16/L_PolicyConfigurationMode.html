Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\lync"
foreach ($name in @('configurationmode', 'serveraddressinternal', 'serveraddressexternal')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\lync"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'configurationmode' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'serveraddressinternal' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    New-ItemProperty -Path $key -Name 'serveraddressexternal' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\lync"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'configurationmode' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\lync"
Remove-ItemProperty -Path $key -Name 'configurationmode', 'serveraddressinternal', 'serveraddressexternal' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Gibt an, wie Microsoft Lync den Server erkennt.

Wenn Sie diese Richtlinieneinstellung aktivieren, müssen Sie den Servernamen eingeben, den Microsoft Lync verwendet.

Wenn Sie diese Richtlinieneinstellung deaktivieren, verwendet Microsoft Lync eine DNS-Suche, um den Server zu erkennen.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, kann der Benutzer die automatische Konfiguration wählen oder den Namen des Servers in den Benutzereinstellungen von Microsoft Lync angeben. Klicken Sie zum Festlegen der Benutzereinstellungen im Menü "Extras" von Microsoft Lync auf "Optionen", klicken Sie auf die Registerkarte "Persönlich", klicken Sie im Bereich "Mein Konto" von "SIP-Kommunikation" auf "Erweitert", wählen Sie "Einstellungen konfigurieren" aus, und geben Sie den Servernamen in das Feld Servername ein.

Hinweis: Sie können diese Richtlinieneinstellung sowohl unter "Computerkonfiguration" als auch unter "Benutzerkonfiguration" konfigurieren, jedoch hat die Richtlinieneinstellung unter "Computerkonfiguration" Vorrang.
