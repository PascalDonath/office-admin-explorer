Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\onenote\options\audio
defaultbitdepthdecimal 8–48

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\options\audio"
foreach ($name in @('defaultbitdepth')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\onenote\options\audio"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'defaultbitdepth' -PropertyType DWord -Value 8 -Force -ErrorAction Stop | Out-Null   # range 8–48
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\options\audio"
Remove-ItemProperty -Path $key -Name 'defaultbitdepth' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify number of bits to sample when recording. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Gibt die Anzahl von Bits pro Sample (Wert in KBit/s) an, die standardmäßig bei der Audioaufnahme verwendet wird. Wenn der geeignete Codec gefunden wird, entspricht dies der Standardbittiefe, die in der Einstellung "Format" für "Verknüpftes Audio" verwendet wird, die sich auf der Registerkarte "Datei" unter "Optionen" | "Audio und Video" befindet.
