Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\options\save"
foreach ($name in @('sharepointlivesyncintervalmultiplier')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\onenote\options\save"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'sharepointlivesyncintervalmultiplier' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # range 1–10
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\options\save"
Remove-ItemProperty -Path $key -Name 'sharepointlivesyncintervalmultiplier' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Multiplier for foreground sync interval for the currently viewed section stored on SharePoint. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Anhand dieser Richtlinieneinstellung können Sie das Intervall zwischen Vordergrundabfragen einer SharePoint-Website zu Änderungen am aktuell angezeigten Abschnitt vergrößern.

Wird diese Richtlinieneinstellung aktivieren, stellt OneNote weniger häufig Abfragen zu Änderungen am aktuell angezeigten Abschnitt an SharePoint. Die Intervalle werden mit dem eingegebenen Wert, einer positiven ganzen Zahl zwischen 1 und 10, multipliziert. Größere Intervalle verlangsamen die Synchronisierung des Abschnitts, verringern jedoch die Serverlast.

Wird diese Richtlinieneinstellung deaktiviert oder nicht konfiguriert, synchronisiert OneNote den aktuell angezeigten Abschnitt anhand der Standardrate (Multiplikator von 1).

Hinweis: Diese Richtlinieneinstellung gilt nur für Volumenlizenzen von Office 2016, die Windows Installer (MSI) verwenden, wie Office Professional Plus 2016 und Office Standard 2016.
