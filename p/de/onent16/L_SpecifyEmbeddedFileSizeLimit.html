insertedfilesdisallowembeddingsizethresholddecimal 10485760–2147483648

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\general"
foreach ($name in @('insertedfilesdisallowembeddingsizethreshold')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\onenote\general"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'insertedfilesdisallowembeddingsizethreshold' -PropertyType DWord -Value 10485760 -Force -ErrorAction Stop | Out-Null   # range 10485760–2147483648
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\general"
Remove-ItemProperty -Path $key -Name 'insertedfilesdisallowembeddingsizethreshold' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Embedded File Size Limit. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen die Angabe der maximal zulässigen Größe für eingebettete Dateien, die von Benutzern direkt in ein OneNote-Notizbuch auf einem SharePoint-Server eingefügt werden können.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie den Standardmaximalwert für die Dateigröße von 50 MB erhöhen oder verringern.

Wenn Sie diesen Wert erhöhen, können Benutzer größere Dateien direkt in das Notizbuch einfügen, was aber die Serverleistung beeinträchtigen kann.

Wenn Sie diesen Wert verringern, können Benutzer nur kleinere Dateien direkt in das Notizbuch einfügen, was die Serverleistung verbessern kann, wenn die OneNote-Synchronisierung ein hohes Datenverkehrsaufkommen generiert.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, können Benutzer keine Dateien in ein OneNote-Notizbuch einfügen, die größer als 50 MB sind. Stattdessen werden solche Dateien dann in einen SharePoint-Ordner hochgeladen und als Link in das Notizbuch eingefügt.
