Automatisches Erstellen verknüpfter Notizen in OneNote deaktivieren

Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft OneNote 2016\OneNote-Optionen\Weitere
User Configuration\Policies\Administrative Templates\Microsoft OneNote 2016\OneNote Options\Other

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\onenote\options\linkednotes
autolinkEnabled = 0 · Disabled = 1

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\options\linkednotes"
foreach ($name in @('autolink')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\onenote\options\linkednotes"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'autolink' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\onenote\options\linkednotes"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'autolink' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\options\linkednotes"
Remove-ItemProperty -Path $key -Name 'autolink' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Turn off OneNote auto-linked note taking. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung deaktiviert das OneNote-Feature zum automatischen Erstellen von Notizen, das es ermöglicht, Notizen zu Elementen wie Webseiten, Word-Dokumente usw. zu erstellen. OneNote zeichnet dabei automatisch auf, welche Seiten oder welches Dokument angezeigt wurde, als die jeweilige Notiz erstellt wurde.

Wenn Sie diese Richtlinieneinstellung aktivieren, werden Notizen in OneNote nicht automatisch verknüpft, wenn der Benutzer versucht, dieses Feature zu aktivieren.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, werden in OneNote Notizen automatisch verknüpft, wenn der Benutzer versucht, dieses Feature zu aktivieren.
