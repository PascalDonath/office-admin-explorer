Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft OneNote 2016\OneNote-Optionen\Sicherheit\Kryptografie
User Configuration\Policies\Administrative Templates\Microsoft OneNote 2016\OneNote Options\Security\Cryptography

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\onenote\security\crypto
cipherchainingChainingModeCBC = Cipher Block Chaining (CBC) · ChainingModeCFB = Cipher Feedback (CFB)

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\security\crypto"
foreach ($name in @('cipherchaining')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\onenote\security\crypto"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'cipherchaining' -PropertyType String -Value 'ChainingModeCBC' -Force -ErrorAction Stop | Out-Null   # options: ChainingModeCBC = Cipher Block Chaining (CBC), ChainingModeCFB = Cipher Feedback (CFB)
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\onenote\security\crypto"
Remove-ItemProperty -Path $key -Name 'cipherchaining' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Configure CNG cipher chaining mode. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen die Konfiguration des verwendeten Chiffreverkettungsmodus.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird der angegebene Chiffreverkettungsmodus angewendet.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, ist "CBC (Blockchiffreverkettung, Cipher Block Chaining)" der verwendete Standardmodus für die CNG-Chiffreverkettung.
