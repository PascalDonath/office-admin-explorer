Microsoft Teams am automatischen Starten nach der Installation hindern

Registrierungswert
preventfirstlaunchafterinstall
GruppenrichtlinieMicrosoft Teams am automatischen Starten nach der Installation hindern
Englische VersionPrevent Microsoft Teams from starting automatically after installation
Intune-EinstellungskatalogPrevent Microsoft Teams from starting automatically after installation (User)
BereichBenutzer · HKCU
ADMXTeams.admx · Teams_PreventFirstLaunchAfterInstall_Policy
Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

User Configuration\Policies\Administrative Templates\Microsoft Teams

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\teams
preventfirstlaunchafterinstallEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\teams"
foreach ($name in @('preventfirstlaunchafterinstall')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\teams"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'preventfirstlaunchafterinstall' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\teams"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'preventfirstlaunchafterinstall' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\teams"
Remove-ItemProperty -Path $key -Name 'preventfirstlaunchafterinstall' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Prevent Microsoft Teams from starting automatically after installation. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung kontrolliert, ob Microsoft Teams automatisch gestartet wird, wenn sich der Benutzer bei einem Gerät anmeldet, nachdem Teams installiert wurde.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird Teams nicht automatisch gestartet, wenn sich der Benutzer bei dem Gerät anmeldet und der Benutzer Teams zuvor noch nicht gestartete hatte.

Hinweis: Wenn Sie diese Richtlinieneinstellung aktivieren, müssen Sie dies vor der Installation von Teams tun.

Sobald ein Benutzer Teams zum ersten Mal startet, wird Teams so konfiguriert, dass es automatisch gestartet wird, wenn sich der Benutzer das nächste Mal bei dem Gerät anmeldet.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird Teams automatisch gestartet, wenn sich ein Benutzer bei dem Gerät anmeldet, nachdem Teams installiert wurde.

Hinweis: Der Benutzer kann Teams so konfigurieren, dass es nicht automatisch gestartet wird, indem er Benutzereinstellungen in Teams konfiguriert.
