Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\excel\options
disableautorepublishEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\options"
foreach ($name in @('disableautorepublish')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\excel\options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disableautorepublish' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\excel\options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disableautorepublish' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\options"
Remove-ItemProperty -Path $key -Name 'disableautorepublish' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable AutoRepublish. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Administratoren das Deaktivieren des Features "Automatisches Wiederveröffentlichen" in Excel. Wenn Benutzer sich entscheiden, Excel-Daten auf einer statischen Webseite zu veröffentlichen und das Feature "Automatisches Wiederveröffentlichen" aktivieren, speichert Excel bei jedem Speichern der Arbeitsmappe eine Kopie der Daten auf der Webseite. Standardmäßig wird bei jedem Speichern einer freigegebenen Arbeitsmappe durch den Benutzer ein Nachrichtendialogfeld angezeigt, wenn "Automatisches Wiederveröffentlichen" aktiviert ist. In diesem Dialogfeld können Benutzer "Automatisches Wiederveröffentlichen" vorübergehend oder dauerhaft deaktivieren oder "Diese Meldung nicht mehr anzeigen" aktivieren, um das Anzeigen des Dialogfelds bei jedem Speichern zu verhindern. Wenn der Benutzer "Diese Meldung nicht mehr anzeigen" aktiviert, fährt Excel mit der automatischen Wiederveröffentlichung von Daten bei jedem Speichern fort, ohne den Benutzer zu informieren.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird das Feature "Automatisches Wiederveröffentlichen" ausgeschaltet, und Excel-Benutzer müssen Daten manuell im Web veröffentlichen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, können Benutzer das Feature "Automatisches Wiederveröffentlichen" aktivieren, um als Typ Webseite gespeicherte Arbeitsmappen automatisch erneut zu veröffentlichen.
