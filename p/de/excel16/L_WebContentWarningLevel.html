Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\excel\security
webservicefunctionwarnings0 = Enable all WEBSERVICE functions (not recommended) · 1 = Disable all with notification · 2 = Disable all without notification

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security"
foreach ($name in @('webservicefunctionwarnings')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\excel\security"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'webservicefunctionwarnings' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Enable all WEBSERVICE functions (not recommended), 1 = Disable all with notification, 2 = Disable all without notification
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security"
Remove-ItemProperty -Path $key -Name 'webservicefunctionwarnings' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach WEBSERVICE Function Notification Settings. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, wie Excel Benutzer warnt, wenn WEBSERVICE-Funktionen vorhanden sind.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie unter drei Optionen wählen, um festzulegen, wie die angegebenen Anwendungen Benutzer hinsichtlich WEBSERVICE-Funktionen warnen:

- Alle mit Benachrichtigung deaktivieren: Die Anwendung zeigt für alle WEBSERVICE-Funktionen die Vertrauensstellungsleiste an. Diese Option setzt die Standardkonfiguration in Office durch.

- Alle ohne Benachrichtigung deaktivieren: Die Anwendung deaktiviert alle WEBSERVICE-Funktionen und benachrichtigt die Benutzer nicht.

- Alle WEBSERVICE-Funktionen aktivieren (nicht empfohlen): Die Anwendung aktiviert alle WEBSERVICE-Funktionen und benachrichtigt Benutzer nicht. Diese Option kann die Sicherheit erheblich verringern, da die Offenlegung von Informationen gegenüber Webdiensten von Drittanbietern zugelassen wird.

Wenn Sie diese Richtlinieneinstellung deaktivieren, ist "Alle mit Benachrichtigung deaktivieren" die Standardeinstellung.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, öffnet Excel beim Öffnen von Arbeitsmappen, die WEBSERVICE-Funktionen enthalten, die Dateien mit deaktivierten WEBSERVICE-Funktionen und zeigt die Vertrauensstellungsleiste mit einer Warnung an, dass WEBSERVICE-Funktionen vorhanden sind und deaktiviert wurden. Die Benutzer können die Dateien gegebenenfalls untersuchen und bearbeiten, jedoch können sie keine deaktivierten Funktionen verwenden, es sei denn, sie geben sie durch Klicken auf "Inhalte aktivieren" in der Vertrauensstellungsleiste frei. Wenn Benutzer auf "Inhalte aktivieren" klicken, wird das Dokument als vertrauenswürdiges Dokument hinzugefügt.
