Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Excel 2016\Verschiedenes
User Configuration\Policies\Administrative Templates\Microsoft Excel 2016\Miscellaneous

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\excel\options
olapudfsecurity1 = Allow ALL UDFs · 2 = Allow safe UDFs only · 3 = Allow NO UDFs

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\options"
foreach ($name in @('olapudfsecurity')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\excel\options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'olapudfsecurity' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # options: 1 = Allow ALL UDFs, 2 = Allow safe UDFs only, 3 = Allow NO UDFs
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\options"
Remove-ItemProperty -Path $key -Name 'olapudfsecurity' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach OLAP PivotTable User Defined Function (UDF) security setting. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

PivotTable-Berichte können OLAP-Abfragen mit Verweisen auf UDFs (User Defined Functions) enthalten. UDFs können kompilierte ausführbare Dateien sein, die deshalb ein potenzielles Sicherheitsrisiko darstellen. Mit dieser Einstellung können Sie (1) zulassen, dass alle UDFs in OLAP-Abfragen ohne IObjectSafety-Prüfung ausgeführt werden, (2) nur UDFs zulassen, bei denen der Entwickler IObjectSafety zum Markieren der UDF als sichere ausführbare Datei verwendet hat, oder (3) die Ausführung aller UDFs in OLAP-Abfragen deaktivieren. Durch Festlegen dieses Schlüssels übergibt Excel den ausgewählten Wert an den OLAP-Anbieter.
