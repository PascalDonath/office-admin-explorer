Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\excel\security\trusted documents
maxtrusteddocumentsdecimal 0–20000

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security\trusted documents"
foreach ($name in @('maxtrusteddocuments')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\excel\security\trusted documents"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'maxtrusteddocuments' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # range 0–20000
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security\trusted documents"
Remove-ItemProperty -Path $key -Name 'maxtrusteddocuments' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Set maximum number of trusted documents. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen die Angabe der maximalen Anzahl von Vertrauensstellungs-Datensätzen für vertrauenswürdige Dokumente, die in der Registrierung gespeichert werden können, bevor der Löschtask ausgeführt wird. Der Löschtask verringert die Anzahl der in der Registrierung gespeicherten vertrauenswürdigen Dokumente auf den Wert, der durch die Richtlinieneinstellung "Maximale Anzahl beizubehaltender Vertrauensstellungs-Datensätze festlegen" festgelegt wird.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie die maximale Anzahl von vertrauenswürdigen Dokumenten mit einer Obergrenze von 20.000 angeben, die in der Registrierung gespeichert werden, bevor der Löschtask ausgeführt wird. Aus Gründen der Leistung empfiehlt es sich nicht, den Wert auf den oberen Grenzwert festzulegen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird der Standardwert von 500 für die maximale Anzahl vertrauenswürdiger Dokumente verwendet, die in der Registrierung gespeichert werden können, bevor der Löschtask ausgeführt wird.
