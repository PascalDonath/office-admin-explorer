Pfad der Gruppenrichtlinie

User Configuration\Policies\Administrative Templates\Microsoft Excel 2016\Excel Options\Security

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\excel\security
excelbypassencryptedmacroscan0 = Scan encrypted macros (default) · 1 = Scan if anti-virus software available · 2 = Load macros without scanning

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security"
foreach ($name in @('excelbypassencryptedmacroscan')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\excel\security"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'excelbypassencryptedmacroscan' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Scan encrypted macros (default), 1 = Scan if anti-virus software available, 2 = Load macros without scanning
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security"
Remove-ItemProperty -Path $key -Name 'excelbypassencryptedmacroscan' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Scan encrypted macros in Excel Open XML workbooks. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung wird gesteuert, ob vor dem Öffnen von verschlüsselten Makros in Open XML-Arbeitsmappen die Überprüfung mit Virenschutzsoftware vorgeschrieben werden soll.

Wenn Sie diese Richtlinieneinstellung aktivieren, stehen Ihnen folgende Optionen zur Verfügung:

- Verschlüsselte Makros überprüfen: Verschlüsselte Makros werden deaktiviert, wenn keine Virenschutzsoftware installiert ist. Verschlüsselte Makros werden von Ihrem Virenschutzprogramm überprüft, wenn Sie versuchen, eine verschlüsselte Arbeitsmappe zu öffnen, die Makros enthält.

- Überprüfen, wenn Virenschutzsoftware verfügbar: Wenn Virenschutzsoftware installiert ist, werden die verschlüsselten Makros vor dem Laden überprüft. Wenn keine Virenschutzsoftware installiert ist, werden verschlüsselte Makros geladen.

- Makros ohne Überprüfung laden: Es wird nicht nach einer Virenschutzsoftware gesucht, und Makros in verschlüsselten Dateien werden geladen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, entspricht das Verhalten der Option "Verschlüsselte Makros überprüfen".
