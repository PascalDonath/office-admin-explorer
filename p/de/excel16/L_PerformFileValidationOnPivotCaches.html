Dateiüberprüfung in PivotTable-Caches ausführen

Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Excel 2016\Excel-Optionen\Sicherheit
User Configuration\Policies\Administrative Templates\Microsoft Excel 2016\Excel Options\Security

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\excel\security\filevalidation
pivotoptions0 = No file validation · 1 = Web and email sources · 2 = Always perform validation

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security\filevalidation"
foreach ($name in @('pivotoptions')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\excel\security\filevalidation"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'pivotoptions' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = No file validation, 1 = Web and email sources, 2 = Always perform validation
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\excel\security\filevalidation"
Remove-ItemProperty -Path $key -Name 'pivotoptions' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Perform file validation on pivot caches. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Dieser Richtlinienschlüssel konfiguriert, ob PivotTable-Caches einer Dateiüberprüfung unterzogen und somit auf Sicherheitsrisiken überprüft werden sollen oder nicht, wenn Dokumente im Excel 97-2003-Format geöffnet werden.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie eine der folgenden Optionen auswählen:

- "Keine Dateiüberprüfung": Die Dateiüberprüfung wird für keine Excel-Dateien in PivotTable-Caches ausgeführt (nicht empfohlen).

- "Web- und E-Mail-Quellen": Die Dateiüberprüfung wird für Dokumente in PivotTable-Caches ausgeführt, die aus dem Internet oder einer E-Mail stammen, sowie für alle Dokumente, die beim Laden PivotTable-Caches auslösen (Standardeinstellung).

- "Überprüfung immer ausführen": Die Dateiüberprüfung wird immer für alle Excel-Dateien in PivotTable-Caches ausgeführt.

Diese Einstellung kann durch die Objektmodelleigenschaft "Application.FileValidationPivot" außer Kraft gesetzt werden.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird die Einstellung "Web- und E-Mail-Quellen" angewendet.
