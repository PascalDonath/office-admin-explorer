Keine Umleitungswarnungen für AutoErmittlung für die angegebenen HTTPS-Servernamen anzeigen

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Don’t show redirect warnings for Autodiscover for the specified HTTPS server names. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht es Ihnen, HTTPS-Servernamen anzugeben, für die AutoErmittlung beim Umleiten von HTTP zu HTTPS keine Warnmeldung zeigt.

Standardmäßig wird Ihnen eine Warnmeldung über die Umleitung angezeigt, wenn ein AutoErmittlungsvorgang von HTTP zu HTTPS umgeleitet wird.

Wenn Sie diese Richtlinieneinstellung aktivieren, müssen Sie HTTPS-Servernamen angeben. Für diese Servernamen wird keine Warnmeldung angezeigt. Wenn Sie z. B. contoso.com eingeben, wird keine Warnmeldung angezeigt, wenn die AutoErmittlung auf https://contoso.com umleitet.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird möglicherweise eine Warnmeldung angezeigt, wenn ein AutoErmittlungsvorgang von HTTP zu HTTPS umgeleitet wird.
