Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\options\mail
blockextcontentEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
foreach ($name in @('blockextcontent')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'blockextcontent' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'blockextcontent' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
Remove-ItemProperty -Path $key -Name 'blockextcontent' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Display pictures and external content in HTML e-mail. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob Outlook nicht vertrauenswürdige Bilder und externe Inhalte herunterlädt, die sich in HTML-E-Mail-Nachrichten befinden, ohne dass Benutzer den Download ausdrücklich auswählen.

Wenn Sie diese Richtlinieneinstellung aktivieren, lädt Outlook nicht automatisch Inhalte von externen Servern herunter, es sei denn, der Absender ist in der Liste der sicheren Absender enthalten. Empfänger können wahlweise externe Inhalte von nicht vertrauenswürdigen Absendern nachrichtenweise herunterladen.

Wenn Sie diese Richtlinieneinstellung deaktivieren, zeigt Outlook Bilder und externe Inhalte in HTML-E-Mails automatisch an.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, lädt Outlook externe Inhalte in HTML-E-Mails und RSS-Elementen nur dann herunter, wen die Inhalte als sicher betrachtet werden. Outlook kann konfiguriert werden, die folgenden Inhalte als sicher zu betrachten:

- Inhalte in E-Mail-Nachrichten von Absendern und an Empfänger, die in den Listen sicherer Absender und sicherer Empfänger definiert sind.

- Inhalte von Websites in der Sicherheitszone "Vertrauenswürdige Websites" von Internet Explorer.

- Inhalte in RSS-Elementen.

- Inhalte aus SharePoint-Diskussionsrunden. Benutzer können steuern, welche Inhalte als sicher betrachtet werden, indem sie die Optionen im Abschnitt "Automatischer Download" des Trust Centers ändern. Wenn die Standardsperrkonfiguration von Outlook im Trust Center oder durch eine andere Methode außer Kraft gesetzt wird, zeigt Outlook externe Inhalte in allen HTML-E-Mail-Nachrichten an (auch solchen, die Webbeacons enthalten).
