Gesamtzahl der Tage in einer Besprechungs- oder Terminserie angeben

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\options\calendar
recurrencesdefaultdecimal 2–720

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\calendar"
foreach ($name in @('recurrencesdefault')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\calendar"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'recurrencesdefault' -PropertyType DWord -Value 2 -Force -ErrorAction Stop | Out-Null   # range 2–720
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\calendar"
Remove-ItemProperty -Path $key -Name 'recurrencesdefault' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify total number of days in a recurring meeting or appointment. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinie erlaubt Ihnen festzulegen, nach welcher Anzahl Tage eine Besprechungs- oder Terminserie (nicht jedoch eine Aufgabe) standardmäßig endet.

Wenn Sie diese Richtlinie aktivieren, wird die Einstellung "Endet am" als Standardeinstellung für Besprechungs- und Terminserien verendet, und der Wert von "Endet am" wird auf die angegebene Anzahl Tage nach dem aktuellen Datum festgelegt. Wenn Sie z. B. einen Wert von 180 angeben, und heute der 5. Mai 2011 ist, ist der Wert von "Endet am" der 1. November 2011 (180 Tage nach dem heutigen Datum).

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, ist die Option "Kein Enddatum" die Standardeinstellung für Besprechungs- und Terminserien.
