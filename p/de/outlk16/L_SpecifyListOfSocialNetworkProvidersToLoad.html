providersecuritymodeEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\outlook\socialconnector"
foreach ($name in @('providersecuritymode', 'trustedproviderslist')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\outlook\socialconnector"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'providersecuritymode' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'trustedproviderslist' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\outlook\socialconnector"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'providersecuritymode' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\outlook\socialconnector"
Remove-ItemProperty -Path $key -Name 'providersecuritymode', 'trustedproviderslist' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify list of social network providers to load. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung bestimmt die Liste der Anbieter für soziale Netzwerke, die von Outlook Connector für soziale Netzwerke geladen werden.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie eine Liste mit Anbieter-ProgIDs von Anbietern für soziale Netzwerke eingeben, die von Outlook Connector für soziale Netzwerke geladen werden. Diese Liste muss durch Semikolons getrennt sein. Beachten Sie, dass bei Aktivierung dieser Richtlinieneinstellung nur Anbieter für soziale Netzwerke von Outlook Connector für soziale Netzwerke geladen werden, die auf dieser Liste stehen. Es werden keine anderen Anbieter für soziale Netzwerke geladen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, kann Outlook Connector für soziale Netzwerke jeden vom Benutzer angegebenen Anbieter laden.
