Eingabeaufforderung für Outlook-Objektmodell beim Zugriff auf die Formula-Eigenschaft eines UserProperty-Objekts konfigurieren

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\security
promptoomformulaaccess1 = Prompt User · 2 = Automatically Approve · 0 = Automatically Deny · 3 = Prompt user based on computer security

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\security"
foreach ($name in @('promptoomformulaaccess')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\security"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'promptoomformulaaccess' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # options: 1 = Prompt User, 2 = Automatically Approve, 0 = Automatically Deny, 3 = Prompt user based on computer security
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\security"
Remove-ItemProperty -Path $key -Name 'promptoomformulaaccess' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Configure Outlook object model prompt When accessing the Formula property of a UserProperty object. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, was passiert, wenn ein Benutzer ein benutzerdefiniertes Formular in Outlook entwirft und versucht, ein Adressinformationenfeld an ein Kombinations- oder benutzerdefiniertes Formelfeld zu binden.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie unter vier verschiedenen Optionen wählen, was passiert, wenn ein nicht vertrauenswürdiges Programm versucht, mithilfe der "UserProperties.Find"-Methode des Outlook-Objektmodells auf Adressinformationen zuzugreifen:

- Eingabeaufforderung für Benutzer. Der Benutzer wird aufgefordert, jeden Zugriffsversuch zu genehmigen.

- Automatisch genehmigen. Outlook genehmigt automatisch programmgesteuerte Zugriffsanforderungen von beliebigen Programmen. Diese Option kann eine signifikante Sicherheitslücke erzeugen und wird nicht empfohlen.

- Automatisch ablehnen. Outlook lehnt automatisch programmgesteuerte Zugriffsanforderungen von beliebigen Programmen ab.

- Benutzer basierend auf der Computersicherheit auffordern. Benutzer werden von Outlook nur aufgefordert, wenn Antivirensoftware veraltet ist oder nicht ausgeführt wird.

Wird diese Richtlinieneinstellung deaktiviert oder nicht konfiguriert, verwendet Outlook, wenn ein Benutzer versucht, in einem benutzerdefinierten Formular ein Adressinformationenfeld an ein Kombinations- oder benutzerdefiniertes Formelfeld zu binden, die im Abschnitt "Programmgesteuerter Zugriff" des Trust Centers konfigurierte Einstellung.
