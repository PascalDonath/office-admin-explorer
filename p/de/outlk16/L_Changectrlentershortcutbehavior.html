Verhalten der Tastenkombination STRG+EINGABE ändern

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\preferences
ctrlentersends0 = CTRL+Enter is not a shortcut for sending a message · 1 = CTRL+Enter is a shortcut for sending a message · 2 = CTRL+Enter displays a prompt

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\preferences"
foreach ($name in @('ctrlentersends')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\preferences"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'ctrlentersends' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = CTRL+Enter is not a shortcut for sending a message, 1 = CTRL+Enter is a shortcut for sending a message, 2 = CTRL+Enter displays a prompt
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\preferences"
Remove-ItemProperty -Path $key -Name 'ctrlentersends' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Change CTRL+ENTER shortcut behavior. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mit dieser Richtlinieneinstellung wird gesteuert, ob STRG+EINGABE zum Senden einer E-Mail-Nachricht verwendet werden kann. Sie können dieses Verhalten ändern, so dass STRG+EINGABE nicht das Senden einer E-Mail-Nachricht bewirkt.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie eine der folgenden Optionen wählen:

- "STRG+EINGABE ist kein Kurzbefehl zum Senden einer Nachricht"

- "STRG+EINGABE ist ein Kurzbefehl zum Senden einer Nachricht"

- "STRG+EINGABE zeigt eine Eingabeaufforderung an"

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, können Benutzer mit der Tastenkombination STRG+EINGABE eine E-Mail-Nachricht senden. Standardmäßig werden Benutzer bei der ersten Verwendung der Tastenkombination aufgefordert, das Senden der Nachricht zu bestätigen.
