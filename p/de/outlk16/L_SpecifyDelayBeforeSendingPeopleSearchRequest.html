Verzögerung vor dem Senden von Personensuchanforderungen angeben

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\im"
foreach ($name in @('presencecontactfastsearchdelay')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\im"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'presencecontactfastsearchdelay' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # range 1–100000000
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\im"
Remove-ItemProperty -Path $key -Name 'presencecontactfastsearchdelay' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify delay before sending people search request. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinie wird verwendet, um die Verzögerung festzulegen, mit der Suchanforderungen für Personen aus dem Feld "Kontakt suchen" in Outlook und aus dem Abschnitt "Verwandte Personen", der in der Backstage-Ansicht (Registerkarte "Informationen") von Office-Anwendungen angezeigt wird, zu senden.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie die Verzögerung in Millisekunden zwischen dem Ende (oder einer Pause) der Eingabe im Suchfeld und dem Senden der Suchanforderung durch die Anwendung angeben.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, beträgt die standardmäßige Verzögerung 200 Millisekunden (0,20 Sekunden).
