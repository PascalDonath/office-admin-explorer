Aktualisierungshäufigkeit der Wetterleiste

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\options\calendar
weatherupdatefrequencydecimal 120–10080

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\calendar"
foreach ($name in @('weatherupdatefrequency')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\calendar"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'weatherupdatefrequency' -PropertyType DWord -Value 120 -Force -ErrorAction Stop | Out-Null   # range 120–10080
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\calendar"
Remove-ItemProperty -Path $key -Name 'weatherupdatefrequency' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Weather Bar Update Frequency. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht das Festlegen der Aktualisierungshäufigkeit (in Minuten) für die Wetterleiste.

Wenn Sie diese Richtlinieneinstellung aktivieren, legt Outlook die Aktualisierungshäufigkeit auf den angegebenen Wert fest.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, verwendet Outlook den Standardwert von 120 Minuten.
