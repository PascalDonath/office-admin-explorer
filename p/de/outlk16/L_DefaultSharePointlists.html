Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Default SharePoint lists. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mit dieser Richtlinieneinstellung können Sie SharePoint-Listen bereitstellen.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie eine Liste der SharePoint-Listen-URLs im folgenden Format bereitstellen.

Wertname: SPsite1

Wert: SPsite1 stssync:// URL. Dokumentation finden Sie unter MS-STSSYN.

Wertname: SPSite2

Wert: SPsite2 stssync:// URL. Dokumentation finden Sie unter MS-STSSYN.

Die Liste der bereitgestellten URLs wird beim Start von Outlook gelesen, und die entsprechenden SharePoint-Listen werden den einzelnen Benutzerprofilen hinzugefügt.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, verfügen Benutzer nicht über standardmäßige SharePoint-Listen.
