AutoErmittlung deaktivieren

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\autodiscover"
foreach ($name in @('excludelastknowngoodurl', 'excludescplookup', 'excludehttpsrootdomain', 'excludehttpsautodiscoverdomain', 'excludehttpredirect', 'excludesrvrecord', 'excludeexplicito365endpoint', 'disableautodiscoverv2service')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\autodiscover"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'excludelastknowngoodurl' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'excludescplookup' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'excludehttpsrootdomain' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'excludehttpsautodiscoverdomain' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'excludehttpredirect' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'excludesrvrecord' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'excludeexplicito365endpoint' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'disableautodiscoverv2service' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable AutoDiscover. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen, die AutoErmittlung zu deaktivieren.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie eine oder mehrere der folgenden Optionen auswählen, die in der Funktion AutoErmittlung deaktiviert werden sollen.

"Die letzte als funktionierend bekannte URL ausschließen” – Outlook verwendet die letzte als funktionierend bekannte AutoErmittlungs-URL nicht.

"Die SCP-Objektsuche ausschließen" – Outlook führt keine Active Directory-Abfragen für SCP-Objekte Service Connection Point mit AutoErmittlungsinformationen aus.

"Abfrage der Stammdomäne basierend auf der primären SMTP-Adresse ausschließen" - Outlook verwendet die Stammdomäne Ihrer primären SMTP-Adresse nicht zum Auffinden des AutoErmittlungsdiensts. Wenn Sie z. B. diese Option auswählen, verwendet Outlook die folgende URL nicht: https://<smtp-address-domain>/autodiscover/autodiscover.xml.

"Abfrage für die AutoErmittlungsdomäne ausschließen" - Outlook verwendet die Domäne der AutoErmittlung nicht, um den AutoErmittlungsdienst zu suchen. Beispielsweise verwendet Outlook die folgende URL nicht: https://autodiscover.<smtp-address-domain>/autodiscover/autodiscover.xml

"HTTP-Redirect-Methode ausschließen" - Outlook verwendet die HTTP-Redirect-Methode in der Situation, dass der AutoErmittlungsdienst über keine der HTTPS URLs erreicht werden kann, nicht: https://<smtp-address-domain>/autodiscover/autodiscover.xml oder https://autodiscover.<smtp-address-domain>/autodiscover/autodiscover.xml.

"SRV-Datensatzabfrage in DNS ausschließen" - Outlook verwendet keine SRV-Datensatzsuche in DNS, um den AutoErmittlungsdienst zu suchen.
