Geben Sie die Wartezeit zum Auswerten vertraulicher Inhalte an.

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\options\mail
dlpwaitonsendtimeoutdecimal 0–10000

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
foreach ($name in @('dlpwaitonsendtimeout')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'dlpwaitonsendtimeout' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # range 0–10000
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
Remove-ItemProperty -Path $key -Name 'dlpwaitonsendtimeout' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify wait time to evaluate sensitive content. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung wird verwendet, um die Wartezeit für die Bewertung vertraulicher Inhalte in E-Mails festzulegen, bevor ein Benutzer sie versenden kann. Legen Sie fest, ob der Versand von E-Mails sofort erlaubt ist, ob der Versand nach einer bestimmten Wartezeit erlaubt ist oder ob vor dem Versand eine vollständige Auswertung erforderlich ist. Unabhängig von der Einstellung wird der Dienst die Bewertung im Hintergrund fortsetzen und auf der Grundlage der Ergebnisse geeignete Maßnahmen ergreifen, wie z. B. die Sperrung der Zustellung, falls erforderlich.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht festlegen, werden E-Mails sofort versendet, ohne die endgültige Auswertung der konfigurierten Richtlinien abzuwarten

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie eine bestimmte Wartezeit festlegen, die in Sekunden gemessen wird (im Bereich von 0–9999), bevor die Schaltfläche „Trotzdem senden“ im Wartedialog erscheint. Dadurch können Benutzer die E-Mail bereits versenden, bevor die Bewertung der Richtlinie abgeschlossen ist.

Beachten Sie, dass das Festlegen einer Wartezeit von mehr als 9999 bedeutet, dass Benutzer die E-Mail nicht ohne Prüfung senden dürfen. In solchen Fällen wird die Schaltfläche „Trotzdem senden“ nie angezeigt.
