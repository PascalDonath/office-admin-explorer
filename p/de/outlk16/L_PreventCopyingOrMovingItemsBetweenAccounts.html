Kopieren und Verschieben von Elementen zwischen Konten verhindern

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

disablecrossaccountcopymultiText

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook"
foreach ($name in @('disablecrossaccountcopy')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablecrossaccountcopy' -PropertyType MultiString -Value @('<value1>', '<value2>') -Force -ErrorAction Stop | Out-Null   # your values
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook"
Remove-ItemProperty -Path $key -Name 'disablecrossaccountcopy' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Prevent copying or moving items between accounts. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen zu verhindern, dass Elemente in andere Konten oder PST-Dateien kopiert oder verschoben werden.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird das Verschieben bzw. Kopieren von Elementen in andere Konten oder PST-Dateien verhindert. Geben Sie eins der folgenden Details ein:

- "Contoso.com": Verhindert das Kopieren bzw. Verschieben aus dem Konto, das der aufgelisteten Domäne entspricht.

- "*": Verhindert das Kopieren aller Konten und PST-Dateien.

- "SharePoint": Verhindert das Kopieren bzw. Verschieben aus der SharePoint-PST-Datei.

Wird diese Richtlinieneinstellung deaktiviert oder nicht konfiguriert, ist das Kopieren und Verschieben von Elementen zwischen Konten oder PST-Dateien zulässig.
