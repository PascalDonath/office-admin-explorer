Benutzereinträge in Serverliste deaktivieren

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\meetings\profile
serverui1 = Publish default, allow others · 2 = Publish default, disallow others

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\meetings\profile"
foreach ($name in @('serverui')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\meetings\profile"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'serverui' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # options: 1 = Publish default, allow others, 2 = Publish default, disallow others
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\meetings\profile"
Remove-ItemProperty -Path $key -Name 'serverui' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable user entries to server list. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob Benutzer von Outlook der Liste der SharePoint-Server Einträge hinzufügen können, wenn Sie einen Besprechungsarbeitsbereich einrichten.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie zwischen zwei Optionen wählen, die bestimmen, ob Benutzer von Outlook der veröffentlichten Serverliste Einträge hinzufügen können:

- "Veröffentlichungsstandard, andere zulassen". Diese Option ist die Standardkonfiguration in Outlook.

- "Veröffentlichungsstandard, andere nicht zulassen". Diese Option verhindert, dass Benutzer der veröffentlichten Standardserverliste Server hinzufügen können.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, können Benutzer, wenn Sie einen Besprechungsarbeitsbereich erstellen, einen Server aus einer vom Administrator bereitgestellten Standardliste auswählen oder manuell die Adresse eines Servers eingeben, der nicht aufgeführt wird. Diese Option entspricht der Einstellung "Aktiviert - Veröffentlichungsstandard, andere zulassen".
