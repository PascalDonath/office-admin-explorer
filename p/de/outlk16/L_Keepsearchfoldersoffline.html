Suchordner immer offline

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\options\general
searchofflinekeepalivedaysdecimal 0–999

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\general"
foreach ($name in @('searchofflinekeepalivedays')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\general"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'searchofflinekeepalivedays' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # range 0–999
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\general"
Remove-ItemProperty -Path $key -Name 'searchofflinekeepalivedays' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Keep Search Folders offline. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie die Anzahl der Tage angeben, die ein Suchordner, der im Offlinemodus oder Cachemodus ausgeführt wird, aktiv bleiben soll. Nachdem auf einen Suchordner für die angegebene Anzahl Tage kein Zugriff erfolgt ist, wird er in den Ruhezustand versetzt und bleibt nicht mehr auf dem aktuellen Stand der Ordnerinhalte (durch das erneute Anzeigen wird der Suchordner wieder aktiv, und der Timer wird neu gestartet).

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie die Anzahl Tage festlegen, die ein Suchordner im Offlinemodus aktiv bleiben soll.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, bleiben Suchordner immer im Ruhezustand.
