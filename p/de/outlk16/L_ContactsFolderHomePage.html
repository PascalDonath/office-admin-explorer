Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\webview\contacts
showEnabled = yes · Disabled = no
urltext
securityEnabled = yes · Disabled = no

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\webview\contacts"
foreach ($name in @('show', 'url', 'security')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\webview\contacts"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'show' -PropertyType String -Value 'yes' -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'url' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    New-ItemProperty -Path $key -Name 'security' -PropertyType String -Value 'yes' -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\webview\contacts"
Remove-ItemProperty -Path $key -Name 'show', 'url', 'security' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Contacts Folder Home Page. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie die Option "Homepage dieses Ordners standardmäßig anzeigen" auf der Registerkarte "Homepage" im Dialogfeld "Kontakte: Eigenschaften" ändern.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird das Kontrollkästchen "Homepage dieses Ordners standardmäßig anzeigen" aktiviert. Darüber hinaus können Sie eine URL eingeben, die maximal 129 Zeichen lang sein darf.

Wird diese Richtlinieneinstellung deaktiviert oder nicht konfiguriert, ist das Kontrollkästchen "Homepage dieses Ordners standardmäßig anzeigen" deaktiviert.
