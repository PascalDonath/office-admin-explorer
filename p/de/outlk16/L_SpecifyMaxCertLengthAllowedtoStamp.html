Legen Sie die maximale Zertifikatgröße für signierte E-Mails in Antwortszenarien fest.

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
foreach ($name in @('maxcertlengthtostamp')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'maxcertlengthtostamp' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # range 0–16384
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
Remove-ItemProperty -Path $key -Name 'maxcertlengthtostamp' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Set Maximum Certificate Size Limit for Signed Emails in Reply Scenarios.. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert die Höchstgrenze für die Größe des gespeicherten Zertifikats in Exchange Server, wenn eine digital signierte E-Mail mit Outlook beantwortet wird.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie den maximalen Grenzwert für die Größe des gespeicherten Zertifikats bis zu einem Maximum von 16384 KB konfigurieren. Dies hilft, Probleme zu vermeiden, bei denen eine Antwort auf eine digital signierte E-Mail möglicherweise nicht zugestellt oder in den gesendeten Elementen gespeichert wird, weil das Zertifikat des ursprünglichen Absenders zu groß ist.

Wenn Sie diese Richtlinieneinstellung deaktivieren, wird die Höchstgrenze auf den Standardwert von 12921 KB festgelegt, was die Möglichkeiten der Administratoren einschränkt, die maximale Größe des gespeicherten Zertifikats anzupassen.

Wenn Sie die Richtlinieneinstellung nicht festlegen, wird sie als aktiviert behandelt und die Standardhöchstgrenze für die Größe des gespeicherten Zertifikats wird auf 12921 KB festgelegt.
