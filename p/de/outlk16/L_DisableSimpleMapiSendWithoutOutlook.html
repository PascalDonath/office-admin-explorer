Ausführen von Outlook für den Simple MAPI-E-Mail-Versand

Nur klassisches Outlook. Das neue Outlook für Windows ignoriert die meisten dieser Office-Richtlinien – es wird stattdessen über Exchange Online (OWA-Postfachrichtlinie) gesteuert.

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\outlook\options\mail
disablesimplemapisendwithoutoutlookEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
foreach ($name in @('disablesimplemapisendwithoutoutlook')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablesimplemapisendwithoutoutlook' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablesimplemapisendwithoutoutlook' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mail"
Remove-ItemProperty -Path $key -Name 'disablesimplemapisendwithoutoutlook' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Running Outlook for Simple MAPI Mail Sending. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung bestimmt, ob Benutzer E-Mails über Simple MAPI senden können, wenn Outlook nicht aktiv ist.

Wenn Sie diese Richtlinieneinstellung aktivieren, müssen Benutzer Outlook ausführen lassen, um E-Mails über Simple MAPI zu senden. Dadurch werden Benutzer gezwungen, Outlook zum Senden von E-Mails zu öffnen, um sicherzustellen, dass Outlook-Add-Ins ordnungsgemäß ausgeführt werden, bevor die E-Mail gesendet wird.

Wenn Sie diese Richtlinieneinstellung deaktivieren, dürfen Benutzer E-Mails über Simple MAPI senden, unabhängig davon, ob Outlook ausgeführt wird.

Wenn diese Richtlinieneinstellung nicht konfiguriert ist, funktioniert sie so, als wäre sie deaktiviert, sodass Benutzer E-Mails über simple MAPI senden können, ohne Outlook ausführen zu müssen.
