Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\visio\application
tipsdrawingEnabled = 1 · Disabled = 0
tipsdialogsEnabled = 1 · Disabled = 0
tipsrulersEnabled = 1 · Disabled = 0
tipsshapesheetEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\visio\application"
foreach ($name in @('tipsdrawing', 'tipsdialogs', 'tipsrulers', 'tipsshapesheet')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\visio\application"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'tipsdrawing' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'tipsdialogs' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'tipsrulers' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'tipsshapesheet' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\visio\application"
Remove-ItemProperty -Path $key -Name 'tipsdrawing', 'tipsdialogs', 'tipsrulers', 'tipsshapesheet' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Diese Richtlinie hat Optionen: nach <enabled/> je Element ein <data id="…" value="…"/> anhängen. Die Element-IDs stehen in der ADMX-Datei.

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify ScreenTips to appear. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen anzugeben, welche QuickInfos in Visio angezeigt werden, um bei der Identifizierung und Verwendung verschiedener Features zu helfen, einschließlich Zeichnungsfensterlinealen, Steuerpunkten und ShapeSheet-Zellen.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie mindestens eine QuickInfo angeben, die angezeigt wird für:

- Zeichnung

- Dialogfelder

- Lineale

- ShapeSheet

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, werden für die oben aufgelisteten Optionen keine QuickInfos angezeigt.
