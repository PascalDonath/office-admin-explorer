Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\visio\security\trusted documents
maxpreservetrusteddocumentsdecimal 0–20000

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\visio\security\trusted documents"
foreach ($name in @('maxpreservetrusteddocuments')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\visio\security\trusted documents"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'maxpreservetrusteddocuments' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # range 0–20000
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\visio\security\trusted documents"
Remove-ItemProperty -Path $key -Name 'maxpreservetrusteddocuments' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Set maximum number of trust records to preserve. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen die Angabe der maximalen Anzahl beizubehaltender Vertrauensstellungs-Datensätze, wenn der Löschtask erkennt, dass diese Anwendung mehr Vertrauensstellungen besitzt als die Anzahl vertrauenswürdiger Dokumente, die von der Richtlinieneinstellung "Maximale Anzahl vertrauenswürdiger Dokumente festlegen" festgelegt wurde.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie die maximale Anzahl beizubehaltender Vertrauensstellungs-Datensätze mit einer Obergrenze von 20.000 angeben. Aus Gründen der Leistung empfiehlt es sich nicht, den Wert auf den oberen Grenzwert festzulegen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird der Standardwert von 400 verwendet.
