Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\powerpoint\accchecker
nonplaceholdershapesEnabled = 0 · Disabled = 1

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\powerpoint\accchecker"
foreach ($name in @('nonplaceholdershapes')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\powerpoint\accchecker"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'nonplaceholdershapes' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\powerpoint\accchecker"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'nonplaceholdershapes' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\powerpoint\accchecker"
Remove-ItemProperty -Path $key -Name 'nonplaceholdershapes' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Stop checking to ensure a meaningful order of objects on slides. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung verhindert, dass die Barrierefreiheitsprüfung überprüft, ob eine Folie Nichtplatzhalterobjekte enthält, die in falscher Reihenfolge gelesen werden könnten.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird die Barrierefreiheitsprüfung an der Überprüfung gehindert, ob eine Folie Nichtplatzhalterobjekte enthält, die in falscher Reihenfolge gelesen werden könnten.

Wird diese Richtlinieneinstellung deaktiviert oder nicht konfiguriert, werden Folien auf Objekte überprüft, die in falscher Reihenfolge gelesen werden könnten, und alle Probleme werden in der Barrierefreiheitsprüfung angezeigt.
