Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\powerpoint
videooffdefaultvalueinrecordingpresenterviewEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
foreach ($name in @('videooffdefaultvalueinrecordingpresenterview')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'videooffdefaultvalueinrecordingpresenterview' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'videooffdefaultvalueinrecordingpresenterview' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
Remove-ItemProperty -Path $key -Name 'videooffdefaultvalueinrecordingpresenterview' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Turn off camera recording by default when recording a slide show. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht es Ihnen, die Kameraaufzeichnung standardmäßig zu deaktivieren, wenn eine Bildschirmpräsentation aufgezeichnet wird.

Standardmäßig ist die Kameraaufzeichnung aktiviert, wenn ein Benutzer zum ersten Mal eine Bildschirmpräsentation aufzeichnet. Wenn der Benutzer die Kameraaufzeichnung deaktiviert, ist die Kameraaufzeichnung beim nächsten Start des Fensters für die Aufzeichnung einer Bildschirmpräsentation deaktiviert, auch wenn PowerPoint geschlossen und erneut geöffnet wird.

Wenn Sie diese Richtlinieneinstellung aktivieren, ist die Kameraaufzeichnung standardmäßig deaktiviert. Ein Benutzer kann die Kameraaufzeichnung aktivieren, wenn eine Bildschirmpräsentation aufgezeichnet wird. Wenn aber das Fenster für die Aufzeichnung einer Bildschirmpräsentation das nächste Mal gestartet wird, ist die Kameraaufzeichnung standardmäßig deaktiviert.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird der Standardzustand der Kameraaufzeichnung vom Benutzer festgelegt, es sei denn, die Richtlinieneinstellung "Mikrofonaufzeichnung standardmäßig während der Aufzeichnung einer Bildschirmpräsentation deaktivieren" ist aktiviert. Durch das Aktivieren dieser Richtlinieneinstellung wird ebenfalls die Kameraaufzeichnung standardmäßig deaktiviert.
