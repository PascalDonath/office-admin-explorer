Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\powerpoint
disableincrementaldownloadEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
foreach ($name in @('disableincrementaldownload')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disableincrementaldownload' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disableincrementaldownload' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\powerpoint"
Remove-ItemProperty -Path $key -Name 'disableincrementaldownload' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Wait to show users a cloud-based presentation until all content is downloaded. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung erlaubt es Ihnen zu kontrollieren, ob PowerPoint wartet, bis alle Inhalte heruntergeladen sind, bevor dem Benutzer eine Präsentation angezeigt wird. Diese Richtlinieneinstellung gilt für Präsentationen, die von einem cloudbasierten Speicherort aus geöffnet werden, z. B. OneDrive – Persönlich, OneDrive for Business oder SharePoint Online.

Standardmäßig kann der Benutzer, wenn er eine cloudbasierte Präsentation in PowerPoint öffnet, die Präsentation anzeigen, während weitere Inhalte wie Bilder oder Videos weiter heruntergeladen werden. Einige Funktionen, wie das Bearbeiten und Präsentieren, sind aber nur eingeschränkt oder gar nicht verfügbar, solange nicht der gesamte Inhalt der Präsentation heruntergeladen ist.

Wenn Sie diese Richtlinieneinstellung aktivieren, wartet PowerPoint beim Öffnen einer cloudbasierten Präsentation, bis der gesamte Inhalt der Präsentation heruntergeladen ist, bevor dem Benutzer die Präsentation angezeigt wird.

Sie können diese Richtlinieneinstellung aktivieren, wenn Sie Add-Ins oder automatisierte Prozesse haben, die darauf basieren, dass der gesamte Inhalt der Präsentation verfügbar und vollständig bearbeitbar ist, sobald die Präsentation angezeigt wird.

Wenn Sie diese Einstellung deaktivieren oder nicht konfigurieren, öffnet PowerPoint cloudbasierte Dateien schneller, sodass der Benutzer mit dem Anzeigen der Präsentation beginnen kann, während die anderen Inhalte noch heruntergeladen werden.

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office wie Microsoft 365 Apps for Enterprise.
