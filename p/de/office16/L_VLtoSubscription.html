Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common\officeupdate
vltosubscriptionEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
foreach ($name in @('vltosubscription')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'vltosubscription' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'vltosubscription' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
Remove-ItemProperty -Path $key -Name 'vltosubscription' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Diese Richtlinieneinstellung erlaubt es Ihnen, ein Upgrade von volumenlizenzierten Versionen von Office Professional Plus 2019 auf Microsoft 365 Apps for Enterprise vorzunehmen.

Hinweis: Damit der Benutzer Microsoft 365 Apps for Enterprise verwenden kann, müssen Sie einen Office 365- oder Microsoft 365-Plan gekauft haben, der Microsoft 365 Apps for Enterprise enthält, und Sie müssen dem Benutzer eine Lizenz zur Verwendung von Microsoft 365 Apps for Enterprise zugewiesen haben.

Wenn Sie diese Richtlinieneinstellung aktivieren, erfolgt ein Upgrade der installierten volumenlizenzierten Version von Office 2019 auf dem Computer des Benutzers auf Microsoft 365 Apps for Enterprise. Wir empfehlen außerdem, dass Sie eine Gruppenrichtlinie verwenden, um einen Updatepfad sowie einen Updatekanal für Microsoft 365 Apps for Enterprise anzugeben.

Hinweis: Wenn auf dem Computer des Benutzers volumenlizenzierte Versionen von Visio und Project vorhanden sind, erfolgt für diese kein Upgrade auf Abonnementversionen von Visio und Project.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird kein automatisches Upgrade von Office 2019 auf Microsoft 365 Apps for Enterprise durchgeführt. Sie können das Upgrade aber initiieren, indem Sie eine andere Methode verwenden, z. B. das Office-Bereitstellungstool.
