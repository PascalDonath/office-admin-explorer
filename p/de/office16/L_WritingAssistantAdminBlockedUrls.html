Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Web pages blocked by Writing Assistance admin policy. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

This policy setting allows administrators to specify a list of web page URL patterns where Writing Assistance will be blocked.

If you enable this policy setting, enter one URL pattern per line (e.g., example.com). Writing Assistance will be disabled on pages matching those patterns.

If you disable or do not configure this policy setting, Writing Assistance will not be blocked by this policy on any web page.
