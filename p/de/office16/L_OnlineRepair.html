Registrierung

WertDaten

onlinerepairEnabled = 1 · Disabled = 0

localodtpathtext

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
foreach ($name in @('onlinerepair', 'fallbacktocdn', 'localodtpath')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'onlinerepair' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'fallbacktocdn' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'localodtpath' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'onlinerepair' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
Remove-ItemProperty -Path $key -Name 'onlinerepair', 'fallbacktocdn', 'localodtpath' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob Benutzer eine Onlinereparatur für einen Office-Client wie Microsoft 365 Apps for Enterprise, der in einem Office 365- oder Microsoft 365-Plan enthalten ist, ausführen können. Sie können außerdem steuern, ob die Onlinereparatur nur eine lokale Quelle und nicht das Office Content Delivery Network (CDN) im Internet verwendet.

Hinweis: Benutzer müssen Administratorrechte auf dem lokalen Computer besitzen, um eine Onlinereparatur auszuführen.

Wenn Sie diese Richtlinieneinstellung aktivieren oder nicht konfigurieren, können Benutzer eine Onlinereparatur in der Systemsteuerung über "Programme und Funktionen" oder "Programme hinzufügen/entfernen" ausführen.

Die Onlinereparatur lädt Office aus dem Office CDN oder von einer lokalen Quelle, z. B. einer Netzwerkfreigabe, herunter, je nachdem wie der Bezug von Updates für Office konfiguriert ist, und installiert es neu. Wenn Sie das Office CDN nicht verwenden, muss die lokale Quelle alle erforderlichen Dateien enthalten, einschließlich Sprachdateien, um die Reparatur durchzuführen.

Wählen Sie "Office CDN verwenden (falls erforderlich)" aus, wenn Sie das Office CDN als alternativen Speicherort für die Reparatur verwenden möchten, falls die lokale Quelle nicht verfügbar ist oder nicht alle notwendigen Dateien enthält.

Sie können auch eine lokale Kopie des Office-Bereitstellungstools (setup.exe) für die Reparatur verwenden, indem Sie einen lokalen Pfad für das Office-Bereitstellungstool eingeben. Dieser Pfad kann eine Netzwerkfreigabe sein. Wenn "setup.exe" in dem angegebenen lokalen Pfad nicht gefunden wird und "Office CDN verwenden (falls erforderlich)" ausgewählt ist, lädt die Onlinereparatur eine Kopie von "setup.exe" aus dem Office CDN herunter. Andernfalls schlägt die Onlinereparatur fehl.

Die Reparatur behält alle Konfigurationseinstellungen bei, einschließlich Produkten, Sprachen, ausgeschlossenen Anwendungen und Updateeinstellungen.

Wenn Sie diese Richtlinieneinstellung deaktivieren, können Benutzer keine Onlinereparatur ausführen, aber sie können immer noch eine Schnellreparatur ausführen.

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office wie Microsoft 365 Apps for Enterprise sowie für Abonnementversionen von Project und Visio.
