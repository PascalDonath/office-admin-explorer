Deaktivieren Sie die Sicherheit lokaler Inhalte zum und vom Szenario „Umschreiben“ für den Benutzer.

Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016\AI\Inhalt Sicherheit\Spezifisch\Umschreiben

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite
disablecontentsafetyEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite"
foreach ($name in @('disablecontentsafety')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablecontentsafety' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablecontentsafety' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite"
Remove-ItemProperty -Path $key -Name 'disablecontentsafety' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Intune (Einstellungskatalog)

Im aktuellen Export des Einstellungskatalogs nicht gefunden. Im Katalog suchen nach Disable local content safety to and from the Rewrite scenario for the user. (Microsoft Office 2016 › AI › Content Safety › Specific › Rewrite).

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable local content safety to and from the Rewrite scenario for the user.. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung deaktiviert die lokale Inhaltssicherheit des Szenarios „Umschreiben“ für den Benutzer.

Bei der Richtlinie für lokale Inhaltssicherheit haben szenariospezifische Einstellungen Vorrang vor allgemeinen Einstellungen und Computereinstellungen haben Vorrang vor Benutzereinstellungen.

Wenn keine Richtlinieneinstellung mit höherer Priorität konfiguriert ist, dann:

- Wenn diese Richtlinieneinstellung aktiviert ist, ist die lokale Inhaltssicherheit für das Szenario „Umschreiben“ für den Benutzer deaktiviert.

- Wenn diese Richtlinieneinstellung deaktiviert ist, wird die lokale Inhaltssicherheit für das Szenario „Umschreiben“ für den Benutzer aktiviert.

- Wenn diese Richtlinieneinstellung nicht konfiguriert ist, wird die lokale Inhaltssicherheit für das Szenario „Umschreiben“ durch Richtlinieneinstellungen mit niedrigerer Priorität bestimmt.

- Wenn diese Richtlinieneinstellung nicht konfiguriert ist und die Richtlinieneinstellungen mit niedrigerer Priorität ebenfalls nicht konfiguriert sind, ist die lokale Inhaltssicherheit für das Szenario „Umschreiben“ für den Benutzer aktiviert.

Für diese Richtlinieneinstellung gilt folgende Rangfolge:

1. Deaktivieren Sie die lokale Inhaltssicherheit zum und vom Szenario „Umschreiben“ für den Computer.

2. Deaktivieren der lokalen Inhaltssicherheit für den Computer im Allgemeinen.

3. Deaktivieren Sie die Sicherheit lokaler Inhalte zum und vom Szenario „Umschreiben“ für den Benutzer.

4. Deaktivieren Sie die Sicherheit lokaler Inhalte generell für den Benutzer.
