Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\signatures
enablecreationofweakxpsignaturesEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\signatures"
foreach ($name in @('enablecreationofweakxpsignatures')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\signatures"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'enablecreationofweakxpsignatures' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\signatures"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'enablecreationofweakxpsignatures' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\signatures"
Remove-ItemProperty -Path $key -Name 'enablecreationofweakxpsignatures' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Legacy format signatures. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mit dieser Richtlinieneinstellung wird gesteuert, ob Benutzer digitale Signaturen im Binärformat auf Office 97-2003-Dokumente anwenden können.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird von Office 2016-Anwendungen das Office 2003-Binärformat verwendet, um digitale Signaturen auf Office 97-2003-Binärdokumente anzuwenden, damit sie von der Office-Version 2003 und früheren Anwendungen erkannt werden.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird von Office 2016-Anwendungen das XML-basierte XMLDSIG-Format verwendet, um digitale Signaturen an Dokumente anzufügen, einschließlich Office 97-2003-Binärdokumente. XMLDSIG-Signaturen werden von Office 2003-Anwendungen oder früheren Versionen nicht erkannt. Wenn ein Office 2003-Benutzer ein Excel-, PowerPoint- oder Word-Binärdokument mit angefügter XMLDSIG-Signatur öffnet, geht die Signatur verloren.
