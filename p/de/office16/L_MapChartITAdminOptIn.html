Erlauben Sie Map Charts, geografische Daten an Bing zu senden

Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016\Diagrammeinstellungen
User Configuration\Policies\Administrative Templates\Microsoft Office 2016\Graph settings

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\charting
aremapchartsenabledEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\charting"
foreach ($name in @('aremapchartsenabled')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\charting"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'aremapchartsenabled' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\charting"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'aremapchartsenabled' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\charting"
Remove-ItemProperty -Path $key -Name 'aremapchartsenabled' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Allow Map Charts to send geographic data to Bing. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob Kartendiagramme geografische Daten an Bing senden können. Weitere Informationen zu Kartendiagrammen finden Sie unter https://go.microsoft.com/fwlink/?linkid=2194000.

Wenn Sie diese Richtlinieneinstellung aktivieren und ein Benutzer geografische Daten zu einem neuen oder vorhandenen Kartendiagramm hinzufügt, werden diese Daten an Bing gesendet, und das Kartendiagramm wird aktualisiert, um neue Standorte einzuschließen.

Wenn Sie diese Richtlinieneinstellung deaktivieren und ein Benutzer einem neuen oder vorhandenen Kartendiagramm geografische Daten hinzufügt, werden die geografischen Daten nicht an Bing gesendet, und das Kartendiagramm wird nicht aktualisiert, um neue Standorte einzuschließen. Außerdem wird dem Benutzer eine Meldung angezeigt, in der er informiert wird, dass sein Kartendiagramm nicht erstellt werden kann.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, werden diese Daten an Bing gesendet, wenn ein Benutzer einem neuen oder vorhandenen Kartendiagramm geografische Daten hinzufügt, und das Kartendiagramm wird aktualisiert, um neue Standorte einzuschließen.

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office, z. B. Microsoft 365 Apps for Enterprise.
