Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'suppressofficechannelselector' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Enabled
    $key = "$root\Software\policies\microsoft\office\16.0\common\officechannelexposure"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'insiderfast' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'firstreleasecurrent' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'current' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'monthlyenterprise' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'firstreleasedeferred' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'deferred' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob die Option Updatekanal unter „Datei“ > „Konto“ in einer Office App, wie z. B. Word, angezeigt wird. Mit dieser Option können Benutzer auswählen, über welchen Update-Kanal sie Office-Updates erhalten möchten.

Weitere Informationen zu Updatekanälen finden Sie unter https://go.microsoft.com/fwlink/p/?linkid=846105.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird die Option Updatekanal unter „Datei“ > „Konto“ angezeigt. Sie müssen auswählen, welche Updatekanäle Benutzern als Optionen angezeigt werden sollen.

Wichtig:

– Benutzer müssen ein lokaler Administrator auf dem Gerät sein, um zu einem anderen Updatekanal zu wechseln.

– Der Beta-Kanal ist kein unterstützter Updatekanal. Er sollte nur in Testumgebungen und von einer kleinen Gruppe ausgewählter Benutzer verwendet werden, z. B. von IT-Mitarbeitern oder Anwendungsentwicklern.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird die Option Updatekanal unter „Datei“ > „Konto“ nicht angezeigt.

Hinweise:

– Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office, z. B. Microsoft 365 Apps für Unternehmen, und für Abonnementversionen von Project und Visio.

– Diese Richtlinieneinstellung hat Vorrang vor der Richtlinieneinstellung „Option für Microsoft 365 Insider anzeigen“ in Fällen, in denen beide Richtlinieneinstellungen aktiviert sind.

– Wenn Sie diese Richtlinieneinstellung aktivieren, sollten Sie die Richtlinieneinstellungen „Zielversion“, „Updatekanal“ oder „Updatepfad“ unter Computerkonfiguration\Policies\Administrative Vorlagen\Microsoft Office 2016 (Maschine)\Updates nicht aktivieren und konfigurieren. Wenn Sie dies tun, haben diese Richtlinieneinstellungen Vorrang. Die Option „Updatekanal“ wird weiterhin unter „Datei“ > „Konto“ angezeigt, aber sie wird deaktiviert und der Benutzer kann keinen Updatekanal auswählen.
