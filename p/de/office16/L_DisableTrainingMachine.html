Training aller Features auf dem Computer deaktivieren

Registrierungswert
disabletraining
GruppenrichtlinieTraining aller Features auf dem Computer deaktivieren
Englische VersionDisable local training of all features for the computer.
Intune-EinstellungskatalogDisable local training of all features for the computer.
BereichComputer · HKLM
ADMXoffice16.admx · L_DisableTrainingMachine
Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

Computerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016 (Computer)\AI\Training\General
Computer Configuration\Policies\Administrative Templates\Microsoft Office 2016 (Machine)\AI\Training\General

Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common\ai\training\general
disabletrainingEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\training\general"
foreach ($name in @('disabletraining')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ai\training\general"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disabletraining' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ai\training\general"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disabletraining' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\training\general"
Remove-ItemProperty -Path $key -Name 'disabletraining' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Mit dieser Richtlinieneinstellung können Sie das Training aller Features auf dem Computer deaktivieren.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird das Training aller Features auf dem Computer deaktiviert.

Wenn Sie diese Richtlinieneinstellung deaktivieren, wird das Training aller Features auf dem Computer aktiviert.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, wird das Training aller Features basierend auf den Benutzerrichtlinieneinstellungen bestimmt.
