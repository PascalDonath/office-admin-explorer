Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\writingassistant
writingassistantinstallandstartupadminchoice0 = Not installed · 1 = Installed, don't launch at startup · 3 = Installed, don't launch at startup by default (users can enable) · 2 = Installed, launch at startup · 4 = Installed, launch at startup by default (users can disable)

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
foreach ($name in @('writingassistantinstallandstartupadminchoice')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'writingassistantinstallandstartupadminchoice' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Not installed, 1 = Installed, don't launch at startup, 3 = Installed, don't launch at startup by default (users can enable), 2 = Installed, launch at startu
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
Remove-ItemProperty -Path $key -Name 'writingassistantinstallandstartupadminchoice' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Configure Writing Assistance installation and startup. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

This policy setting controls whether Writing Assistance is not installed, installed without launching automatically at startup and locked off, installed without launching automatically at startup but still user-controllable, installed and allowed to launch automatically at startup and locked on, or installed with startup on by default but still user-controllable.

If you enable this policy setting, choose one of the following options:

- Not installed: Writing Assistance is removed and should not appear in Start.

- Installed, don't launch at startup: Writing Assistance remains installed, but automatic startup launches are blocked and users cannot turn startup back on.

- Installed, don't launch at startup by default (users can enable): Writing Assistance remains installed, automatic startup launches are off by default, and users can turn startup on later.

- Installed, launch at startup: Writing Assistance remains installed, automatic startup launches are allowed, and users cannot turn startup off.

- Installed, launch at startup by default (users can disable): Writing Assistance remains installed, automatic startup launches are on by default, and users can turn startup off later.

If you disable or don't configure this policy setting, Writing Assistance follows its default install and startup behavior, and users can control startup themselves.

Note: This policy setting only applies to subscription versions of Office, such as Microsoft 365 Apps for Enterprise.
