Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\internet
relyonvmlEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\internet"
foreach ($name in @('relyonvml')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\internet"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'relyonvml' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\internet"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'relyonvml' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\internet"
Remove-ItemProperty -Path $key -Name 'relyonvml' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Rely on VML for displaying graphics in browsers. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mit dieser Richtlinieneinstellung wird gesteuert, ob Office 2016-Anwendungen beim Speichern von Dokumenten als Webseiten Kopien von VML-Grafiken (Vector Markup Language) in einem Standard-Rasterdateiformat (GIF oder PNG) speichern.

Wenn Sie diese Richtlinieneinstellung aktivieren, erstellen Office 2016-Anwendungen keine alternativen Dateien für VML-Grafiken, wenn Dokumente als Webseiten gespeichert werden. Darüber hinaus ist in Excel, PowerPoint und Word das Kontrollkästchen "Für Grafikdarstellung in Browsern auf VML vertrauen" im Dialogfeld "Weboptionen" aktiviert, und Benutzer können die Einstellung nicht ändern.

Wenn Sie diese Richtlinieneinstellung deaktivieren, speichern Office 2016-Anwendungen außerdem Kopien der Grafiken in einem Standard-Rasterdateiformat (GIF oder PNG) für die Verwendung in Browsern, die VML nicht anzeigen können. Ferner ist in Excel, PowerPoint und Word das Kontrollkästchen "Für Grafikdarstellung in Browsern auf VML vertrauen" im Dialogfeld "Weboptionen" deaktiviert, und Benutzer können die Einstellung nicht ändern.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, speichern Office 2016-Anwendungen beim Speichern von VML-Grafiken außerdem Kopien der Grafiken in einem Standard-Rasterdateiformat (GIF oder PNG) für die Verwendung in Browsern, die VML nicht anzeigen können. Wenn das Kontrollkästchen "Für Grafikdarstellung in Browsern auf VML vertrauen" im Dialogfeld "Weboptionen" aktiviert ist, speichern Anwendungen keine Rasterkopieren von VML-Grafiken, d.h. diese Grafiken werden in nicht von Microsoft stammenden Browsern nicht angezeigt.
