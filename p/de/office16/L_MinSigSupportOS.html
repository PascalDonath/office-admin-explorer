Registrierung

WertDaten
HKCU\Software\policies\microsoft\vba\security
minsigsupportos0 = Windows XP · 1 = Windows Vista · 2 = Windows 7 · 3 = Windows 8

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\vba\security"
foreach ($name in @('minsigsupportos')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\vba\security"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'minsigsupportos' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Windows XP, 1 = Windows Vista, 2 = Windows 7, 3 = Windows 8
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\vba\security"
Remove-ItemProperty -Path $key -Name 'minsigsupportos' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Set the minimum operating system for verifying agile VBA signatures. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht es Ihnen, das mindestens erforderliche Betriebssystem (BS) festzulegen, unter dem von Office erzeugte agile Signaturen überprüft werden können. Dadurch wird sichergestellt, dass der zum Signieren verwendete Hashalgorithmus mit dem angegebenen BS und späteren Versionen kompatibel ist.

Wenn Sie diese Richtlinieneinstellung aktivieren, verwendet Office das von Ihnen als mindestens erforderlich festgelegte Betriebssystem zur Überprüfung von agilen VBA-Signaturen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, verwendet Office Windows 7 als mindestens erforderliches BS zur Überprüfung von agilen VBA-Signaturen.

Wenn Sie eine mindestens erforderliche BS-Version angeben, die höher als das höchste von Office unterstützte BS ist, verwendet Office das höchste unterstützte BS zur Überprüfung von agilen VBA-Signaturen.
