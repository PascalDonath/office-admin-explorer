Pfad der Gruppenrichtlinie

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\common\smart tag
neverloadmanifestsEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\common\smart tag"
foreach ($name in @('neverloadmanifests')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\common\smart tag"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'neverloadmanifests' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\common\smart tag"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'neverloadmanifests' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\common\smart tag"
Remove-ItemProperty -Path $key -Name 'neverloadmanifests' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable Smart Document's use of manifests. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung wird gesteuert, ob Office 2016-Anwendungen eine Manifestdatei für ein XML-Erweiterungspaket mit einem SmartDocument laden können.

Ein XML-Erweiterungspaket ist die Gruppe von Dateien, aus denen sich in Excel und Word ein SmartDocument zusammensetzt. Die für ein SmartDocument erforderliche Logik wird von einer oder mehreren Komponente(n) bereitgestellt, die mithilfe eines XML-Erweiterungspakets als Paket zusammengefasst werden. Diese Komponenten können jeden beliebigen Dateityp, einschließlich XML-Schemas, XSLTs (Extensible Stylesheet Language-Transformationsdateien), DLLs (Dynamic-Link Libraries) und Bilddateien sowie weitere XML-Dateien, HTML-Dateien, Word-Dateien, Excel-Dateien und Textdateien enthalten.

Die Schlüsselkomponente bei der Generierung eines XML-Erweiterungspakets besteht im Erstellen der Manifestdatei für das XML-Erweiterungspaket. Beim Erstellen dieser Datei geben Sie die Speicherorte aller Dateien an, aus denen sich das XML-Erweiterungspaket zusammensetzt, zusammen mit Informationen, die Office 2016 anweisen, wie die Dateien für das SmartDocument einzurichten sind. Das XML-Erweiterungspaket kann darüber hinaus Informationen zum Einrichten einiger Dateien enthalten, wie etwa zur Installation und Registrierung eines COM-Objekts, das vom XML-Erweiterungspaket benötigt wird.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Office 2016-Anwendungen keine XML-Erweiterungspakete mit SmartDocuments laden.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, können Office 2016-Anwendungen eine Manifestdatei eines XML-Erweiterungspakets zusammen mit einem SmartDocument laden.
