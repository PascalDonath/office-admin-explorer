Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\contactcard
turnoncontacttablabelreplace7text

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\contactcard"
foreach ($name in @('turnoncontacttablabelreplace7')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\contactcard"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'turnoncontacttablabelreplace7' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\contactcard"
Remove-ItemProperty -Path $key -Name 'turnoncontacttablabelreplace7' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Replace Label - Home2. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie die siebte Beschriftung auf der Registerkarte "Kontakt" ändern oder entfernen, die sich auf der Visitenkarte befindet. Die Standardwerte für die Beschriftungen der Registerkarte "Kontakt" lauten "E-Mail" (E-Mail-Adresse), "Arbeit" (Telefon geschäftlich), "Arbeit2" (Telefon geschäftlich 2), "FaxGeschäft" (Fax geschäftlich), "Mobil" (Mobiltelefon), "Privat" (Telefon (privat)), "Privat2" (Telefon (privat) 2), "Weitere" (Weiteres Telefon), "Chat" (Chatadresse), "Profil" (Profil), "Büro" (Bürostandort), "Unternehmen" (Unternehmen), "Geschäftsadresse" (Geschäftsadresse), "Privatadresse" (Privatadresse ), "Weitere Adresse" (Weitere Adresse ) und "Geburtstag" (Geburtstag).

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie die Beschriftungen auf der Registerkarte "Kontakt" ändern oder entfernen, indem Sie eine neue Textzeichenfolge in das Textfeld unten eingeben.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird die Standardbeschriftung angezeigt.
