Allow Copilot to Search Files on This Device

Microsoft liefert diese Richtlinie auch in der deutschen ADML nur auf Englisch.

Registrierungswert
copilotdevicesearchenabled
GruppenrichtlinieAllow Copilot to Search Files on This Device
Englische VersionAllow Copilot to Search Files on This Device
BereichComputer · HKLM
ADMXoffice16.admx · L_CopilotDeviceSearchEnabled
Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

Computerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016 (Computer)\Microsoft 365 Copilot
Computer Configuration\Policies\Administrative Templates\Microsoft Office 2016 (Machine)\Microsoft 365 Copilot

Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common
copilotdevicesearchenabledEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common"
foreach ($name in @('copilotdevicesearchenabled')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'copilotdevicesearchenabled' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'copilotdevicesearchenabled' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common"
Remove-ItemProperty -Path $key -Name 'copilotdevicesearchenabled' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

This policy setting controls whether Copilot can search for files on the PC.

If you enable or do not configure this policy setting, Copilot can search for files on the device.

If you disable this policy setting, Copilot cannot search for files; other read features remain available.

For more information, see https://aka.ms/copilot-device-tools

Note: This policy setting only applies to subscription versions of Microsoft 365 Copilot on Windows and macOS desktop apps.
