Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\contactcard
turnoncontacttabadreplace2text

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\contactcard"
foreach ($name in @('turnoncontacttabadreplace2')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\contactcard"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'turnoncontacttabadreplace2' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\contactcard"
Remove-ItemProperty -Path $key -Name 'turnoncontacttabadreplace2' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Replace AD - Work. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie den zweiten Wert auf der Registerkarte "Kontakt" anpassen.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie den Standardwert ("Telefon (Arbeit)") in Zeile 2 ändern oder entfernen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird der Standardwert für Zeile 2 angezeigt.

Wichtig:

Es wird empfohlen, eine MAPI-Eigenschaft (Messaging Application Programming Interface) und ein entsprechendes Active Directory-Attribut (AD-Attribut) anzugeben. Die MAPI-Eigenschaft sollte immer angegeben werden, wenn Outlook nicht installiert ist. In diesem Fall muss nur das AD-Attribut angegeben werden. Es muss im folgenden Format angegeben werden: ADAttribute. Alle eingegeben Eigenschaften, die binär oder Listenfelder sind, können nicht angezeigt werden und werden ignoriert.

Beispiel:

Wenn Sie den Assistenten für die Visitenkarte anzeigen möchten, geben Sie das AD-Attribut ein: Ms-exch-assistant-name.

Geben Sie zum Entfernen des Werts Folgendes ein: null.

Hinweis:

Die Werte "Standort" und "Kalender" für eine Standardvisitenkarte sind keine MAPI-Eigenschaften oder AD-Attribute.

Verwandte Richtlinieneinstellungen:

MAPI-Eigenschaft n ersetzen, "Registerkarte 'Kontakt': Zeile 'Kalender' verschieben" aktivieren, "Registerkarte 'Kontakt': Zeile 'Speicherort' verschieben" aktivieren.
