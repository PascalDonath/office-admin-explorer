PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\general"
foreach ($name in @('allowedsexualcontent')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\general"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'allowedsexualcontent' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # range 0–7
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\general"
Remove-ItemProperty -Path $key -Name 'allowedsexualcontent' -ErrorAction SilentlyContinue

Erklärung von Microsoft

Mit dieser Einstellung für die lokale Inhaltssicherheitsrichtlinie wird der zulässige Schweregrad von sexuellen Inhalten im Allgemeinen für den Computer angepasst. Der zulässige Schweregrad kann von 0 bis 7 reichen.

0 bedeutet, dass keine sexuellen Inhalte erlaubt sind.

7 bedeutet, dass alle sexuellen Inhalte zulässig sind.

Weitere Informationen zu den Schweregraden der Inhaltssicherheit finden Sie in der folgenden Dokumentation:

https://learn.microsoft.com/en-us/azure/ai-services/content-safety/concepts/harm-categories?tabs=definitions

Bei der lokalen Inhaltssicherheitsrichtlinie haben szenariospezifische Einstellungen Vorrang vor allgemeinen Einstellungen und Computereinstellungen haben Vorrang vor Benutzereinstellungen.

Wenn keine Richtlinieneinstellung mit höherer Priorität konfiguriert ist, gilt Folgendes:

– Wenn diese Richtlinieneinstellung nicht konfiguriert ist, wird der zulässige Schweregrad von sexuellen Inhalten im Allgemeinen durch Richtlinieneinstellungen mit niedrigerer Priorität bestimmt.

– Wenn diese Richtlinieneinstellung nicht konfiguriert ist und auch keine Richtlinieneinstellungen mit niedrigerer Priorität konfiguriert sind, ist der zulässige Schweregrad von sexuellen Inhalten im Allgemeinen standardmäßig auf 2 eingestellt.

Für diese Richtlinieneinstellung gilt die folgende Rangfolge:

1. Zulässiger Schweregrad von sexuellen Inhalten von und nach [einem spezifischen Szenario] für den Computer.

2. Zulässiger Schweregrad sexueller Inhalte im Allgemeinen für den Computer.

3. Zulässiger Schweregrad von sexuellen Inhalten von und nach [einem spezifischen Szenario] für den Benutzer.

4. Zulässiger Schweregrad von sexuellen Inhalten im Allgemeinen für den Benutzer.
