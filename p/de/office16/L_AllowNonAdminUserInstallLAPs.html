Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\languageresources
allownonadminuserinstalllanguagesEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
foreach ($name in @('allownonadminuserinstalllanguages')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'allownonadminuserinstalllanguages' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'allownonadminuserinstalllanguages' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
Remove-ItemProperty -Path $key -Name 'allownonadminuserinstalllanguages' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Allow users who aren’t admins to install language accessory packs. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob Benutzer Sprachzubehörpakete für Office selbst dann installieren können, wenn sie nicht über lokale Administratorberechtigungen auf ihren Geräten verfügen. Standardmäßig müssen die Benutzer über lokale Administratorberechtigungen auf ihren Geräten verfügen, um Sprachzubehörpakete installieren zu können.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Benutzer Sprachzubehörpakete für Office selbst dann installieren, wenn sie nicht über lokale Administratorberechtigungen auf ihren Geräten verfügen. Sie können diese Sprachzubehörpakete installieren, indem sie in der App zu "Datei>optionen>" (Sprache in der App, z. B. Word) gehen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, können Benutzer, die nicht über lokale Administratorberechtigungen auf ihren Geräten verfügen, keine Sprachzubehörpakete installieren. Eine Person mit lokalen Administratorberechtigungen für das Gerät muss die Sprachzubehörpakete für den Benutzer installieren.

Weitere Informationen finden Sie unter https://go.microsoft.com/fwlink/p/?linkid=2161939.
