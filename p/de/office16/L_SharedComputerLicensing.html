Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common\licensing
sharedcomputerlicensingEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
foreach ($name in @('sharedcomputerlicensing')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'sharedcomputerlicensing' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'sharedcomputerlicensing' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
Remove-ItemProperty -Path $key -Name 'sharedcomputerlicensing' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob die Aktivierung gemeinsam genutzter Computer verwendet wird, um die auf dem Computer installierte Version von Office zu aktivieren. Standardmäßig wird die Aktivierung des gemeinsam genutzten Computers nicht für die Aktivierung verwendet.

Die Aktivierung gemeinsam genutzter Computer wird nur in Situationen verwendet, in denen mehrere Benutzer denselben Computer gemeinsam nutzen. Zum Beispiel bei der Verwendung von Remote Desktop Services (RDS).

Wenn Sie diese Richtlinieneinstellung aktivieren, wird die gemeinsame Computeraktivierung verwendet, um die auf dem Computer installierte Version von Office zu aktivieren.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, wird die Aktivierung gemeinsam genutzter Computer nicht verwendet, um die auf dem Computer installierte Version von Office zu aktivieren, es sei denn, Sie haben die Aktivierung gemeinsam genutzter Computer mithilfe des Office-Bereitstellungstools aktiviert.

Wenn Sie diese Richtlinieneinstellung deaktivieren, wird die Aktivierung gemeinsam genutzter Computer nicht verwendet, selbst wenn sie mit dem Office-Bereitstellungstool festgelegt wurde.

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementpläne, die Microsoft 365 Apps for Enterprise enthalten, und für Abonnementversionen von Project und Visio.
