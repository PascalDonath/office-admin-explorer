Lock Writing Assistance admin blocklist

Microsoft liefert diese Richtlinie auch in der deutschen ADML nur auf Englisch.

Registrierungswert
adminblocklistlocked
GruppenrichtlinieLock Writing Assistance admin blocklist
Englische VersionLock Writing Assistance admin blocklist
Intune-EinstellungskatalogLock Writing Assistance admin blocklist (User)
BereichBenutzer · HKCU
ADMXoffice16.admx · L_WritingAssistantAdminBlocklistLocked
Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

User Configuration\Policies\Administrative Templates\Microsoft Office 2016\Writing Assistance

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\writingassistant
adminblocklistlockedEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
foreach ($name in @('adminblocklistlocked')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'adminblocklistlocked' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'adminblocklistlocked' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
Remove-ItemProperty -Path $key -Name 'adminblocklistlocked' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Lock Writing Assistance admin blocklist. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

This policy setting controls whether users can modify the admin-managed Writing Assistance blocklist.

If you enable this policy setting (or do not configure it), the admin blocklist is locked and users cannot remove entries from it.

If you disable this policy setting, users can remove individual entries from the admin-provided blocklist.
