Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite"
foreach ($name in @('allowedhatecontent')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'allowedhatecontent' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # range 0–7
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\ai\contentsafety\specific\rewrite"
Remove-ItemProperty -Path $key -Name 'allowedhatecontent' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Mit dieser Einstellung für die lokale Sicherheitsrichtlinie für Inhalte wird der zulässige Schweregrad von Hassinhalten zum und vom Szenario „Umschreiben“ für den Computer angepasst. Der zulässige Schweregrad kann von 0 bis 7 reichen.

0 bedeutet, dass keine Hassinhalte erlaubt sind.

7 bedeutet, dass alle Hassinhalte erlaubt sind.

Weitere Informationen zu den Sicherheitsstufen für Inhalte finden Sie in der folgenden Dokumentation:

https://learn.microsoft.com/en-us/azure/ai-services/content-safety/concepts/harm-categories?tabs=definitions

Bei lokalen Sicherheitsrichtlinien für Inhalte haben szenariospezifische Einstellungen Vorrang vor allgemeinen Einstellungen und Computereinstellungen haben Vorrang vor Benutzereinstellungen.

- Wenn diese Richtlinieneinstellung nicht konfiguriert ist, wird der zulässige Schweregrad von Hassinhalten zum und vom Szenario „Umschreiben“ durch Richtlinieneinstellungen mit niedrigerer Priorität bestimmt.

- Wenn diese Richtlinieneinstellung nicht konfiguriert ist und auch keine Richtlinieneinstellungen mit niedrigerer Priorität konfiguriert sind, ist der zulässige Schweregrad von Hassinhalten zum und vom Szenario „Umschreiben“ standardmäßig auf 2 festgelegt.

Für diese Richtlinieneinstellung gilt die folgende Prioritätsreihenfolge:

1. Erlaubter Schweregrad von Hassinhalten zum und vom Szenario „Umschreiben“ für den Computer.

2. Erlaubter Schweregrad von Hassinhalten im Allgemeinen für den Computer.

3. Erlaubter Schweregrad von Hassinhalten in und aus dem Szenario „Umschreiben“ für den Benutzer.

4. Erlaubter Schweregrad von Hassinhalten im Allgemeinen für den Benutzer.
