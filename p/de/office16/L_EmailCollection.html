Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\feedback
includeemailEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\feedback"
foreach ($name in @('includeemail')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\feedback"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'includeemail' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\feedback"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'includeemail' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\feedback"
Remove-ItemProperty -Path $key -Name 'includeemail' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Allow Microsoft to follow up on feedback submitted by users​. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, ob Microsoft das Feedback von Benutzern weiterverfolgen kann, um das Feedback zu verstehen, ein Problem zu beheben, das durch das Feedback übermittelt wurde, oder um mitzuteilen, wie Microsoft das Feedback zur Verbesserung des Produkts genutzt hat. Sie ermöglicht es dem Benutzer auch, über den Status seines Feedbacks auf dem Laufenden zu bleiben. Standardmäßig kann Microsoft mit Ihren Benutzern auf das von ihnen eingereichte Feedback reagieren.

Microsoft darf Transaktions-E-Mails senden oder darf in Bezug auf das Feedback oder die Umfrageantwort um Unterhaltungen zur Nachverfolgung per E-Mail, Sprache oder auf anderem Weg bitten. In manchen Fällen bittet Microsoft möglicherweise um weitere Informationen, um die Problembehandlung zu unterstützen.​

Wenn Sie diese Richtlinieneinstellung aktivieren oder nicht konfigurieren, kann Microsoft mit Ihren Benutzern Kontakt aufnehmen, wenn diese ihr Feedback abgegeben haben. Die Benutzer können sich gegen die Kommunikation entscheiden, wenn sie nicht wegen ihres Feedbacks kontaktiert werden möchten.​

Wenn Sie diese Richtlinieneinstellung deaktivieren, wird Microsoft die von Ihren Benutzern eingereichten Rückmeldungen nicht weiterverfolgen.​

Sie können das Feedback Ihrer Organisation im Microsoft 365 Admin Center einsehen und verwalten.​

Hinweis: Diese Richtlinieneinstellung hat keinen Effekt, wenn die Richtlinieneinstellungen “Benutzern gestatten, Feedback an Microsoft zu übermitteln” oder "Benutzern das Empfangen von und reagieren auf Umfragen von Microsoft innerhalb von Produkten gestatten" deaktiviert sind.​

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office (z. B. Microsoft 365 Apps for Enterprise), Project und Visio.​

Hinweis: Das in dieser Richtlinie beschriebene Verhalten gilt ab dem 21. Juli 2023.
