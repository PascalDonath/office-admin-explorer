Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\security\applicationguard
clipboarddirection0 = Enable clipboard operation both directions (default) · 1 = Enable clipboard operation only from the host to the isolated session · 2 = Enable clipboard operation only from an isolated session to the host · 3 = Disable clipboard operation both directions
clipboardformats0 = Enable only text operations in the clipboard (default). · 1 = Enable only image operations in the clipboard. · 2 = Enable image and text operations in the clipboard.

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\security\applicationguard"
foreach ($name in @('clipboarddirection', 'clipboardformats')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\security\applicationguard"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'clipboarddirection' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Enable clipboard operation both directions (default), 1 = Enable clipboard operation only from the host to the isolated session, 2 = Enable clipboard operat
    New-ItemProperty -Path $key -Name 'clipboardformats' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Enable only text operations in the clipboard (default)., 1 = Enable only image operations in the clipboard., 2 = Enable image and text operations in the cli
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\security\applicationguard"
Remove-ItemProperty -Path $key -Name 'clipboarddirection', 'clipboardformats' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Configure copy and paste from Office documents opened in Application Guard. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mit dieser Richtlinieneinstellung können Sie bestimmen, ob Benutzer Inhalte von Office in und aus Dokumenten, die in Application Guard geöffnet sind, kopieren und einfügen können, sowie die zulässigen Formate. Diese Richtlinie gilt nur für Word, Excel und PowerPoint.

Wenn Sie diese Richtlinie aktivieren, müssen Sie unter folgenden Verhaltensweisen auswählen:

– Zwischenablagefunktion zwischen Host und Application Guard aktivieren (Standard).

– Zwischenablagefunktion zwischen Host und Application Guard vollständig deaktivieren.

– Zwischenablage zum Kopieren von Inhalten von Application Guard zum Host aktivieren.

– Zwischenablage zum Kopieren von Inhalten vom Host zu Application Guard aktivieren.

Hinweis: Application Guard lässt nur das Kopieren von Text und Bildern zu, das Kopieren von komplexen Inhalten ist nicht möglich.

Wichtig: Es wird davon abgeraten, das Kopieren vom Host zu Application Guard zu aktivieren. Wenn Sie diese Funktion aktivieren, kann von einer potenziell gefährdeten Application Guard-Sitzung auf die Zwischenablage des Hostgeräts und auf deren Inhalte zugegriffen werden.

Sie können den Inhaltstyp, der kopiert werden kann aus auswählen, indem Sie die Inhaltsoptionen verwenden:

– Lässt das Kopieren von Text zu (Standard).

– Lässt das Kopieren von Bildern zu.

– Lässt das Kopieren von Text und Bildern zu.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, können Benutzer Inhalte in und aus Dokumenten, die in Application Guard geöffnet sind, kopieren und an anderer Stelle außerhalb von Application Guard einfügen.

Hinweis: Application Guard lässt nur das Kopieren von Text und Bildern zu, das Kopieren von komplexen Inhalten ist nicht möglich.

Hinweis: Diese Richtlinieneinstellung gilt nur für Microsoft 365 Apps for Enterprise.
