Writing Assistance First Run Experience Mode

Microsoft liefert diese Richtlinie auch in der deutschen ADML nur auf Englisch.

Registrierungswert

GruppenrichtlinieWriting Assistance First Run Experience Mode
Englische VersionWriting Assistance First Run Experience Mode
Intune-EinstellungskatalogWriting Assistance First Run Experience Mode (User)
BereichBenutzer · HKCU

Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

User Configuration\Policies\Administrative Templates\Microsoft Office 2016\Writing Assistance

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\writingassistant
writingassistantfirstrunexperienceadminchoice0 = Skip FRE entirely · 1 = Informational only · 2 = Approval required

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
foreach ($name in @('writingassistantfirstrunexperienceadminchoice')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'writingassistantfirstrunexperienceadminchoice' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Skip FRE entirely, 1 = Informational only, 2 = Approval required
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\writingassistant"
Remove-ItemProperty -Path $key -Name 'writingassistantfirstrunexperienceadminchoice' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Writing Assistance First Run Experience Mode. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

This policy setting controls the Writing Assistance first run experience (FRE).If you enable this policy setting, choose one of the following options:Skip FRE entirely - Writing Assistance marks the first run experience as completed without showing it.Informational only - Writing Assistance shows the first run experience once without requiring user approval or sign-in. The experience is marked completed immediately, uses Next on page 1 and Okay on page 2, removes No Thanks, and is still completed if the user dismisses it.Approval required - Writing Assistance keeps the existing approval-required first run experience behavior.If you disable or don’t configure this policy setting, Writing Assistance uses the existing default first run experience behavior.Note: This policy setting only applies to subscription versions of Office, such as Microsoft 365 Apps for Enterprise.
