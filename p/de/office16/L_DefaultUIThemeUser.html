Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common
default ui theme0 = Colorful · 3 = Dark Gray · 4 = Black · 5 = White

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common"
foreach ($name in @('default ui theme')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'default ui theme' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Colorful, 3 = Dark Gray, 4 = Black, 5 = White
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common"
Remove-ItemProperty -Path $key -Name 'default ui theme' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Default Office theme. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie das Benutzeroberflächendesign auswählen, das von Office verwendet wird, wenn der Benutzer nicht bereits ein Office-Design ausgewählt hat.

Hinweis: Diese Einstellung gilt nur für die Version 1903 oder höher von Office.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie das Office-Design auswählen, das verwendet wird, wenn der Benutzer kein eigenes Office-Design ausgewählt hat.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, verwendet Office das Design "Bunt", wenn der Benutzer kein eigenes Office-Design ausgewählt hat.

Unabhängig davon, wie Sie diese Richtlinieneinstellung konfigurieren, können Benutzer ihr Office-Design ändern, indem sie zu "Datei" > "Konto" > "Office-Design" wechseln (oder in Outlook, indem Sie zu "Datei" > "Office-Konto" > "Office-Design" wechseln).

Hinweis: Die Richtlinieneinstellung "Standarddesign für Office", die sich unter "Computerkonfiguration" befindet, hat Vorrang vor dieser Richtlinieneinstellung.
