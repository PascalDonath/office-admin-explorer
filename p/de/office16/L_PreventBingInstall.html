Keinen Hintergrunddienst für Microsoft Search in Bing installieren

Registrierungswert
preventbinginstall
GruppenrichtlinieKeinen Hintergrunddienst für Microsoft Search in Bing installieren
Englische VersionDon’t install a background service for Microsoft Search in Bing
Intune-EinstellungskatalogDon’t install extension for Microsoft Search in Bing that makes Bing the default search engine
BereichComputer · HKLM
ADMXoffice16.admx · L_PreventBingInstall
Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

Computerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016 (Computer)\Aktualisierungen
Computer Configuration\Policies\Administrative Templates\Microsoft Office 2016 (Machine)\Updates

Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common\officeupdate
preventbinginstallEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
foreach ($name in @('preventbinginstall')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'preventbinginstall' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'preventbinginstall' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
Remove-ItemProperty -Path $key -Name 'preventbinginstall' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Diese Richtlinieneinstellung kontrolliert, ob ein Hintergrunddienst für Microsoft Search in Bing installiert wird. Der Hintergrunddienst wird eingeschlossen, wenn Sie Microsoft 365 Apps for Enterprise zum ersten Mal installieren, oder wenn Sie auf eine neue Version aktualisieren.

Dieser Hintergrunddienst überprüft den Status eines Kontrollkästchens im Abschnitt "Microsoft Search" des Microsoft 365 Admin Centers. Wenn das Kontrollkästchen aktiviert ist, wird eine "Microsoft Search in Bing"-Erweiterung für Google Chrome installiert. Die Erweiterung legt die Standardsuchmaschine auf Bing fest, doch Benutzer können die Standardsuchmaschine auch noch nach Installation der Erweiterung ändern.

Hinweis: Das Kontrollkästchen ist im Microsoft 365 Admin Center standardmäßig nicht aktiviert. Daher bemerken Ihren Benutzer auch keine Änderungen, selbst wenn der Hintergrunddienst installiert ist, außer Sie wechseln in das Microsoft 365 Admin Center und aktivieren das Kontrollkästchen.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird der Hintergrunddienst nicht installiert. Da der Hintergrunddienst nicht installiert wird, wird auch die Erweiterung nicht installiert, auch dann nicht, wenn das Kontrollkästchen im Microsoft 365 Admin Center aktiviert ist.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird der Hintergrunddienst installiert. Selbst wenn der Hintergrunddienst installiert ist, wird die Erweiterung nur dann installiert, wenn das Kontrollkästchen im Microsoft 365 Admin Center aktiviert ist.

Weitere Informationen finden Sie unter https://go.microsoft.com/fwlink/p/?linkid=2109345.
