Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
foreach ($name in @('updatebranch')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'updatebranch' -PropertyType String -Value 'Current' -Force -ErrorAction Stop | Out-Null   # options: Current = Current Channel, FirstReleaseCurrent = Current Channel (Preview), MonthlyEnterprise = Monthly Enterprise Channel, Deferred = Semi-Annual Enterprise Ch
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
Remove-ItemProperty -Path $key -Name 'updatebranch' -ErrorAction SilentlyContinue

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, über welchen Updatekanal Office Updates bezieht.

Wenn Sie diese Richtlinieneinstellung aktivieren, bezieht Office Updates über den von Ihnen ausgewählten Updatekanal.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, bezieht Office Updates über seinen Standardkanal oder über den Updatekanal, der vom Office-Bereitstellungstool angegeben wird. Der Standardkanal hängt davon ab, mit welchem Office-Produkt die Installation erfolgt ist.

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office wie Microsoft 365 Apps for Enterprise und Abonnementversionen von Project und Visio.​
