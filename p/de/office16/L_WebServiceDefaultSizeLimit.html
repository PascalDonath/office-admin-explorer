Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016\Geschäftsdaten\Webdienst
User Configuration\Policies\Administrative Templates\Microsoft Office 2016\Business Data\Web Service

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\business data\limits\wcf\size
defaultdecimal 1–1000000000

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\business data\limits\wcf\size"
foreach ($name in @('default')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\business data\limits\wcf\size"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'default' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # range 1–1000000000
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\business data\limits\wcf\size"
Remove-ItemProperty -Path $key -Name 'default' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Set web service default return size limit. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie den Standardgrenzwert für die Datenmenge im KB angeben, die der Webdienstshim pro Aufruf zurückgeben kann. Die Anwendung darf über den Ausführungskontext einen höheren Grenzwert angeben.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie den Standardgrenzwert für die Datenmenge im KB angeben, die der Webdienstshim pro Aufruf zurückgeben kann.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird ein Standardgrenzwert von 3.000 KB verwendet.
