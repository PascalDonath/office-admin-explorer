Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016\Spracheinstellungen\Anzeigesprache
User Configuration\Policies\Administrative Templates\Microsoft Office 2016\Language Preferences\Display Language

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\languageresources
disablelanguagepackdownloadEnabled = 0 · Disabled = 1
languagepackdownloadaddresstext

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
foreach ($name in @('disablelanguagepackdownload', 'languagepackdownloadaddress')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablelanguagepackdownload' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'languagepackdownloadaddress' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablelanguagepackdownload' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\languageresources"
Remove-ItemProperty -Path $key -Name 'disablelanguagepackdownload', 'languagepackdownloadaddress' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Change or delete link to language pack download site. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung wirkt sich auf den Sprachendownloadlink im Abschnitt zur Anzeige- und Hilfesprache aus.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie die URL zu einem anderen Speicherort eingeben, von dem Sprachpakete heruntergeladen werden können.

Wenn Sie diese Richtlinieneinstellung deaktivieren, wird die URL entfernt.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, bleibt die URL verfügbar und verweist auf die Downloadwebsite für Sprachpakete auf "Office.com".
