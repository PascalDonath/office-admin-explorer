Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common\licensing
orgideduenabledcentennialEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
foreach ($name in @('orgideduenabledcentennial')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'orgideduenabledcentennial' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'orgideduenabledcentennial' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
Remove-ItemProperty -Path $key -Name 'orgideduenabledcentennial' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Diese Richtlinieneinstellung kontrolliert, ob ein Office-Produkt mit dem E-Mail-Konto des Schülers aktiviert wird. Standardmäßig ist eine Anmeldung mit der Organisations-ID nicht zulässig.

Wenn Sie diese Richtlinieneinstellung aktivieren, kann die auf dem Computer installierte Version von Office mit der E-Mail-ID-Anmeldung des Schülers aktiviert werden.

Wenn Sie diese Richtlinieneinstellung deaktivieren, kann die auf dem Computer installierte Version von Office nicht mit der E-Mail-ID-Anmeldung des Schülers aktiviert werden.

Die Aktivierung bzw. Deaktivierung dieser Richtlinieneinstellung hat Vorrang vor allen anderen Einstellungen, die mithilfe des Office-Bereitstellungstools oder durch manuelles Bearbeiten der Registrierung konfiguriert wurden.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, wird die E-Mail-ID-Anmeldung des Schülers nur dann zur Aktivierung der auf dem Computer installierten Version von Office verwendet, wenn Sie die Anmeldung mit Organisations-ID durch manuelles Bearbeiten der Registrierung aktiviert haben.
