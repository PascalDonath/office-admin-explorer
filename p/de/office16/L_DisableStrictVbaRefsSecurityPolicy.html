Registrierung

WertDaten
HKCU\Software\policies\microsoft\vba\security
disablestrictvbarefssecurityEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\vba\security"
foreach ($name in @('disablestrictvbarefssecurity')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\vba\security"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablestrictvbarefssecurity' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\vba\security"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablestrictvbarefssecurity' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\vba\security"
Remove-ItemProperty -Path $key -Name 'disablestrictvbarefssecurity' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable additional security checks on VBA library references that may refer to unsafe locations on the local machine. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung schränkt VBA dahingehend ein, dass Projektbibliotheksverweise nur gegen die Registrierung und gegen vertrauenswürdige Zonen überprüft werden. Standardmäßig führt VBA zusätzliche Überprüfungen gegen Bibliothekspfade durch, um auch das Laden von Verweisen von potenziell unsicheren Speicherorten auf dem lokalen Computer zu verhindern. Es wird empfohlen, dass diese Einstellung auf "0" oder nicht festgelegt bleibt, um das Standardverhalten mit erhöhter Sicherheit zu ermöglichen. Aktivieren Sie diese Einstellung nur, wenn das Standardverhalten Kompatibilitätsprobleme mit kritischen Lösungen verursacht. Und dann auch nur, um Zeit für die Migration der Lösungen bereitzustellen, um das weniger sichere Verhalten zu behandeln, woraufhin dann die Einstellung wieder aktiviert werden sollte.
