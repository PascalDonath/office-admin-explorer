Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\common\security\allowlists\graphicsfilterimport
allowlistenabledEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\common\security\allowlists\graphicsfilterimport"
foreach ($name in @('allowlistenabled')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\common\security\allowlists\graphicsfilterimport"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'allowlistenabled' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\common\security\allowlists\graphicsfilterimport"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'allowlistenabled' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\common\security\allowlists\graphicsfilterimport"
Remove-ItemProperty -Path $key -Name 'allowlistenabled' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen das Angeben einer Liste mit Grafikfiltern, die von Office 2016-Anwendungen geladen werden.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie eine Liste mit Grafikfiltern angeben, die von Office 2016-Anwendungen geladen werden. Die angegebenen Grafikfilter müssen einem Zeichenfolgenwert FILTER.FLT zugewiesen werden (wobei FILTER.FLT durch den Namen eines realen Filters ersetzt wird), dessen Wert XX.YY.ZZ.WW lautet, wobei jeder der Werte XX, YY, ZZ und WW eine positive Zahl kleiner als 2^16 und die Version in der Registrierung niedriger oder gleich der Version des Filters ist. Beispiel: "eigenerfilter.flt"="2006.1200.1000.1000".

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, unterliegen die durch Office 2016-Anwendungen geladenen Grafikfilter keinen Einschränkungen.
