Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016\Dienste

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\roaming
roamingsettingsdisabledEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\roaming"
foreach ($name in @('roamingsettingsdisabled')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\roaming"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'roamingsettingsdisabled' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\roaming"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'roamingsettingsdisabled' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\roaming"
Remove-ItemProperty -Path $key -Name 'roamingsettingsdisabled' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable Roaming Office User Settings. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Microsoft Office bietet die Möglichkeit, Einstellungen für bestimmte Office-Funktionen durch Speichern dieser Daten in der Cloud auf andere Geräte zu übertragen (Roaming). Diese Daten umfassen Benutzeraktivitäten, wie die Liste der zuletzt verwendeten Dokumente, sowie Benutzereinstellungen, wie etwa das Office-Design. Diese Richtlinieneinstellung steuert, ob diese Daten in der Cloud gespeichert werden dürfen.

Wenn Sie diese Richtlinieneinstellung aktivieren, werden Roamingeinstellungen nur lokal gespeichert und nicht mit dem Webdienst für Microsoft Office-Roamingeinstellungen synchronisiert.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, werden Roamingeinstellungen mit dem Webdienst für Microsoft Office-Roamingeinstellungen synchronisiert, und Benutzer können von anderen Geräten aus auf ihre Daten zugreifen.

Diese Richtlinie wirkt sich nicht auf in der Cloud vorhandene Daten aus.
