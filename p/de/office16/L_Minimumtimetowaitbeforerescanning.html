Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\portal\colleagueimport
minimumstaletimedecimal 1–24

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\portal\colleagueimport"
foreach ($name in @('minimumstaletime')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\portal\colleagueimport"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'minimumstaletime' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # range 1–24
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\portal\colleagueimport"
Remove-ItemProperty -Path $key -Name 'minimumstaletime' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Minimum time to wait before rescanning the Outlook mailbox for new colleague recommendations. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Die Mindestwartezeit (in Stunden) bis zum erneuten Überprüfen des Outlook-Postfachs auf neue Kollegenempfehlungen.

Gleiche Kategorie: Microsoft Office 2016 › Servereinstellungen › SharePoint Server

  • Maximale Anzahl der ab heute zu überprüfenden Elemente, um die Kollegen des Benutzers für die Empfehlung zu bestimmenmaximumitemstoscan
  • Maximale Anzahl der ab heute zu überprüfenden Tage, um die Kollegen des Benutzers für die Empfehlung zu bestimmenmaximumdaystoscan
  • Maximale Anzahl von zu überprüfenden Empfängern in einem Outlook-Element, um die Kollegen des Benutzers für die Empfehlung zu bestimmenmaximumreceipientsperitem
  • Kollegenimport-Outlook-Add-In für Microsoft SharePoint Server aktivierenenabled
  • Mindestwartezeit bis zum Beginn der Überprüfung auf Kollegenempfehlungenminimumidletime
  • Die maximale Anzahl der pro Anforderung abgerufenen Zeilen beim Auffüllen eines Lookups im SharePoint-Listensteuerelementrowlimitforlookups
