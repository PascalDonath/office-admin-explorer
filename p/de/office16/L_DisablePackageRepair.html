Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common\openxmlformat
disablepackagerepairEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\openxmlformat"
foreach ($name in @('disablepackagerepair')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\openxmlformat"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablepackagerepair' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\openxmlformat"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'disablepackagerepair' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\openxmlformat"
Remove-ItemProperty -Path $key -Name 'disablepackagerepair' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie die Option zum Reparieren von Open XML-Dokumenten deaktivieren.

Wenn Sie diese Richtlinieneinstellung aktivieren, werden Anwendungen von Office 2016 an der Ausführung einer Reparatur von fehlerhaften Open XML-Dokumenten gehindert.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, erhält der Benutzer die Möglichkeit, wenn eine Office 2016-Anwendung erkennt, dass ein Open XML-Dokument fehlerhaft ist, das fehlerhafte Dokument zu reparieren.
