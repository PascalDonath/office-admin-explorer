Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\ptwatson
ptwoptinEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\ptwatson"
foreach ($name in @('ptwoptin')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ptwatson"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'ptwoptin' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\ptwatson"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'ptwoptin' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\ptwatson"
Remove-ItemProperty -Path $key -Name 'ptwoptin' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Improve Proofing Tools. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mit dieser Richtlinieneinstellung wird gesteuert, ob vom Feature "Helfen Sie, die Korrekturhilfen zu verbessern" Verwendungsdaten an Microsoft gesendet werden. Mit dem Feature "Helfen Sie, die Korrekturhilfen zu verbessern" werden Daten zur Verwendung der Korrekturhilfen gesammelt, wie Hinzufügungen zum benutzerdefinierten Wörterbuch, und an Microsoft gesendet. Nach ca. sechs Monaten wird das Senden von Daten an Microsoft vom Feature eingestellt und die Datensammlungsdatei wird vom Computer des Benutzers gelöscht.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird das Feature aktiviert, wenn die Benutzer sich entscheiden, am Programm zur Verbesserung der Benutzerfreundlichkeit (Customer Experience Improvement Program, CEIP) teilzunehmen. Wenn Ihre Organisation über Richtlinien zum Steuern der Verwendung externer Ressourcen, wie CEIP, verfügt, kann das Zulassen der Verwendung des Features "Helfen Sie, die Korrekturhilfen zu verbessern" eine Verletzung dieser Richtlinien bewirken.

Wenn Sie diese Richtlinieneinstellung deaktivieren, werden mit dem Feature "Helfen Sie, die Korrekturhilfen zu verbessern" keine Informationen zur Verwendung der Korrekturhilfen gesammelt, um sie an Microsoft zu übertragen.

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, ist das Verhalten gleichbedeutend mit dem Festlegen der Richtlinie auf "Aktiviert".
