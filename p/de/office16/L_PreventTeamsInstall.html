Installieren Sie Microsoft Teams nicht mit Neuinstallationen oder Updates von Office

Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

Computerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Office 2016 (Computer)\Aktualisierungen
Computer Configuration\Policies\Administrative Templates\Microsoft Office 2016 (Machine)\Updates

Registrierung

WertDaten
HKLM\Software\policies\microsoft\office\16.0\common\officeupdate
preventteamsinstallEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
foreach ($name in @('preventteamsinstall')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKLM-Werte brauchen eine PowerShell mit erhöhten Rechten.

Aktivieren

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'preventteamsinstall' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'preventteamsinstall' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
Remove-ItemProperty -Path $key -Name 'preventteamsinstall' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie steuern, ob Microsoft Teams mit einer neuen Office-Installation installiert wird, oder wenn eine vorhandene Installation von Office aktualisiert wird.

Hinweis: Diese Richtlinieneinstellung gilt nur für Versionen von Office wie Microsoft 365 Apps for Enterprise, bei denen Teams mit einer neuen Installation oder einem Update von Office installiert wird.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird Teams nicht mit einer neuen Installation oder einem Update von Office installiert.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird Teams im Rahmen einer Neuinstallation oder eines Updates von Office installiert, es sei denn, Sie haben eine andere Methode verwendet, z. B. das Office-Bereitstellungstool, um die Installation von Teams auszuschließen.
