PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\common\workflow\cache\workflow2"
foreach ($name in @('name', 'path', 'description', 'documentlibraryfriendlyname', 'sigclientrequired')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\common\workflow\cache\workflow2"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'name' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    New-ItemProperty -Path $key -Name 'path' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    New-ItemProperty -Path $key -Name 'description' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    New-ItemProperty -Path $key -Name 'documentlibraryfriendlyname' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    New-ItemProperty -Path $key -Name 'sigclientrequired' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\common\workflow\cache\workflow2"
Remove-ItemProperty -Path $key -Name 'name', 'path', 'description', 'documentlibraryfriendlyname', 'sigclientrequired' -ErrorAction SilentlyContinue

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Workflow Cache 2. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Die eingegebenen Werte werden vom Client verwendet, um dem Benutzer einen Workflow bereitzustellen, der dem Benutzer für alle seine Dokumente zur Verfügung gestellt werden soll. Die URL sollte ein vollständiger Pfad sein, beispielsweise "http://localsharepointsite/Shared%20Documents". Für einige Workflows muss der Benutzer ein Dokument mit einer dokumentinternen Signatur signieren. Als solche angegebene Workflows werden dem Benutzer nur als Option in Anwendungen angezeigt, die dokumentinterne Signaturen unterstützen.

Dieser Workflow muss außerdem in der Dokumentbibliothek verfügbar gemacht werden (durch Festlegen dieser Werte wird der Client nur über den Workflow informiert).
