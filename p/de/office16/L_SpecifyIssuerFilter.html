Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\signatures
filterissuertext

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\signatures"
foreach ($name in @('filterissuer')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\signatures"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'filterissuer' -PropertyType String -Value '<value>' -Force -ErrorAction Stop | Out-Null   # your value
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\signatures"
Remove-ItemProperty -Path $key -Name 'filterissuer' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify filtering for certificate issuers. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Mithilfe dieser Richtlinieneinstellung können Sie Office so konfigurieren, dass beim Erstellen einer digitalen Signatur nur Zertifikate eines bestimmten Ausstellers zugelassen werden.

Wenn Sie diese Richtlinieneinstellung aktivieren, zeigt Office nur Zertifikate an, die die von Ihnen in der Richtlinie festgelegte Zeichenfolge enthalten. Diese Einstellung berücksichtigt Groß- und Kleinschreibung.

Beispielsweise entspricht die Einstellung von "MeineZS" den Ausstellern "MeineZS 1"und "MeineZS 2", aber nicht "MEINEZS 3".

Wenn Sie diese Einstellung deaktivieren oder nicht konfigurieren, können Signaturzertifikate beliebiger Aussteller verwendet werden.
