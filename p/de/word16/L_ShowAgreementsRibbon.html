Menüband Vereinbarungen anzeigen

Registrierungswert
showagreementsribbon
GruppenrichtlinieMenüband Vereinbarungen anzeigen
Englische VersionEnable Manage Ribbon
BereichBenutzer · HKCU
ADMXword16.admx · L_ShowAgreementsRibbon
Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

User Configuration\Policies\Administrative Templates\Microsoft Word 2016

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\word\options
showagreementsribbonEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\options"
foreach ($name in @('showagreementsribbon')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'showagreementsribbon' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'showagreementsribbon' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\options"
Remove-ItemProperty -Path $key -Name 'showagreementsribbon' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Intune (Einstellungskatalog)

Im aktuellen Export des Einstellungskatalogs nicht gefunden. Im Katalog suchen nach Enable Manage Ribbon (Microsoft Word 2016).

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Enable Manage Ribbon. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Steuern Sie den Zugriff auf das Menüband „Vereinbarungen“ in Word.

Mit dieser Richtlinieneinstellung können Sie steuern, wer in Ihrer Organisation das Menüband „Vereinbarungen“ in Word sehen kann, und die Funktionen zum Erstellen und Verwalten des Vertragslebenszyklus in Word nutzen.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie Benutzergruppen konfigurieren, denen das Menüband „Vereinbarungen“ angezeigt wird.

Wenn Sie diese Richtlinieneinstellung deaktivieren, steht das Menüband „Vereinbarungen“ den Benutzern Ihrer Organisation nicht zur Verfügung.

Wenn Sie diese Richtlinieneinstellung nicht aktivieren, steht das Menüband „Vereinbarungen“ den Benutzern Ihrer Organisation nicht zur Verfügung.
