LinkedIn Lebenslauf-Assistenten-Funktion zulassen

BereichBenutzer · HKCU

Im interaktiven Explorer öffnen+ Zur Sammlung

Pfad der Gruppenrichtlinie

Benutzerkonfiguration\Richtlinien\Administrative Vorlagen\Microsoft Word 2016\Word-Optionen\Allgemein
User Configuration\Policies\Administrative Templates\Microsoft Word 2016\Word Options\General

Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\word\options
linkedinresumeassistantEnabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\options"
foreach ($name in @('linkedinresumeassistant')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'linkedinresumeassistant' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\options"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'linkedinresumeassistant' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\options"
Remove-ItemProperty -Path $key -Name 'linkedinresumeassistant' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Allow LinkedIn Resume Assistant feature. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung kontrolliert, ob der LinkedIn Lebenslauf-Assistent in Word angezeigt wird.

Wenn Sie diese Richtlinie aktivieren oder nicht konfigurieren, können Benutzer den LinkedIn Lebenslauf-Assistenten verwenden.

Wenn Sie diese Richtlinieneinstellung deaktivieren, ist der LinkedIn Lebenslauf-Assistent nicht verfügbar.

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office wie Microsoft 365 Apps for Enterprise sowie für Abonnementversionen von Project und Visio.
