Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\word\options\vpreffuz
feqb_v_9_1Enabled = 1 · Disabled = 0

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\options\vpreffuz"
foreach ($name in @('feqb_v_9_1')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\options\vpreffuz"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'feqb_v_9_1' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Deaktivieren
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\options\vpreffuz"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'feqb_v_9_1' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\options\vpreffuz"
Remove-ItemProperty -Path $key -Name 'feqb_v_9_1' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Match ba/va, ha/fa. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen das Aktivieren/Deaktivieren der entsprechenden Benutzeroberflächenoption im Dialogfeld "Suchoptionen für Japanisch". Der Zugriff auf das Dialogfeld "Suchoptionen für Japanisch" erfolgt über das Dialogfeld "Suchen" auf der Registerkarte "Start" unter "Bearbeiten" | "Suchen" | "Gehe zu..." | "Suchoptionen" | "Optionen...". Der Zugriff kann auch im Navigationsbereich auf der Registerkarte "Start" | "Bearbeiten" | "Suchen" | <Pfeil nach unten> | "Optionen..." | "Ähnl. Schreibweise (Japanisch)" | "Optionen" erfolgen. Das Kontrollkästchen "Ähnl. Schreibweise (Japanisch)" und die Schaltfläche "Optionen..." werden in Word möglicherweise erst eingeblendet, nachdem bestimmte Bearbeitungssprachen aktiviert wurden.

Wenn Sie diese Richtlinieneinstellung aktivieren, wird die entsprechende Benutzeroberflächenoption aktiviert, wie im Titel dieser Richtlinieneinstellung angegeben.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, wird die entsprechende Benutzeroberflächenoption nicht aktiviert.
