Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\word\security\filevalidation
openinprotectedview0 = Block files · 1 = Open in Protected View
disableeditfrompvEnabled = 0 · Disabled = 1

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\security\filevalidation"
foreach ($name in @('openinprotectedview', 'disableeditfrompv')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\security\filevalidation"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'openinprotectedview' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Block files, 1 = Open in Protected View
    New-ItemProperty -Path $key -Name 'disableeditfrompv' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\security\filevalidation"
Remove-ItemProperty -Path $key -Name 'openinprotectedview', 'disableeditfrompv' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Set document behavior if file validation fails. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung steuert, wie Office Dokumente bei einem Fehlschlagen der Dateiüberprüfung behandelt.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie folgende Optionen für Dateien konfigurieren, deren Dateiüberprüfung fehlgeschlagen ist:

- "Dateien blockieren" (vollständig): Benutzer können die Dateien nicht öffnen.

- "In geschützter Ansicht öffnen und Bearbeitung nicht zulassen": Benutzer können die Dateien nicht bearbeiten. Auf diese Art werden Dateien von Office behandelt, wenn Sie diese Richtlinieneinstellung deaktivieren.

- "In geschützter Ansicht öffnen und Bearbeitung zulassen": Benutzer können die Dateien bearbeiten. Auf diese Art werden Dateien von Office behandelt, wenn Sie diese Richtlinieneinstellung nicht konfigurieren.

Wenn Sie diese Richtlinieneinstellung deaktivieren, verhält sich Office gemäß der Option "In geschützter Ansicht öffnen und Bearbeitung nicht zulassen".

Wenn Sie diese Richtlinieneinstellung nicht konfigurieren, verhält sich Office gemäß der Option "In geschützter Ansicht öffnen und Bearbeitung zulassen".
