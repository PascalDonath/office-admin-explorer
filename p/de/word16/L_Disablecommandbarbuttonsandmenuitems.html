PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\word\disabledcmdbaritemscheckboxes"
foreach ($name in @('filewebpagepreview', 'sendtomailrecipient', 'inserthyperlink', 'flyoutanchorprotectdocumentmenu', 'toolsmacro', 'toolsmacromacros', 'toolsmacrorecord', 'toolsmacrosecurity', 'toolsmacrovbe', 'toolstemplateaddins', 'webaddress')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\word\disabledcmdbaritemscheckboxes"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'filewebpagepreview' -PropertyType DWord -Value 3655 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'sendtomailrecipient' -PropertyType DWord -Value 2188 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'inserthyperlink' -PropertyType DWord -Value 1576 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'flyoutanchorprotectdocumentmenu' -PropertyType DWord -Value 16129 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolsmacro' -PropertyType DWord -Value 16106 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolsmacromacros' -PropertyType DWord -Value 186 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolsmacrorecord' -PropertyType DWord -Value 2780 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolsmacrosecurity' -PropertyType DWord -Value 3627 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolsmacrovbe' -PropertyType DWord -Value 1695 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolstemplateaddins' -PropertyType DWord -Value 751 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'webaddress' -PropertyType DWord -Value 1740 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }

DatentypString
Wert<enabled/> · <disabled/>

Diese Richtlinie hat Optionen: nach <enabled/> je Element ein <data id="…" value="…"/> anhängen. Die Element-IDs stehen in der ADMX-Datei.

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Disable predefined commands. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung ermöglicht Ihnen das Deaktivieren bestimmter Befehle in Microsoft Word. Befehle sind Schaltflächen, Menüs oder andere Elemente, die der Symbolleiste für den Schnellzugriff oder dem Menüband auf der Registerkarte "Datei" unter "Optionen" | "Symbolleiste für den Schnellzugriff" oder auf der Registerkarte "Datei" unter "Optionen" | "Menüband anpassen" hinzugefügt werden können.

Wenn Sie diese Richtlinieneinstellung aktivieren, können Sie angeben, welche Befehle in der Benutzeroberfläche für Word deaktiviert sein sollen.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, sind alle in der vordefinierten Liste enthaltenen Befehle in Word aktiviert.
