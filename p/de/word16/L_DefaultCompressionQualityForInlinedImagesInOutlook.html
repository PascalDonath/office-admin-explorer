Registrierung

WertDaten
HKCU\Software\policies\microsoft\office\16.0\common\mailsettings
oulookimagedpiindex0 = High Fidelity · 1 = 330 ppi · 2 = 220 ppi · 3 = 150 ppi · 4 = 96 ppi

Nicht konfiguriert = der Wert existiert nicht – es gilt der Standard der Anwendung, Benutzer dürfen die Einstellung ändern.

PowerShell

Aktuellen Wert prüfen (nur lesen)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\mailsettings"
foreach ($name in @('oulookimagedpiindex')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Adminrechte nötig: HKCU\Software\Policies ist für Standardbenutzer schreibgeschützt. Eine erhöhte Sitzung schreibt in das HKCU des Admins – für einen anderen angemeldeten Benutzer $root auf Registry::HKEY_USERS\<SID> ändern.

Aktivieren

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\mailsettings"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'oulookimagedpiindex' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = High Fidelity, 1 = 330 ppi, 2 = 220 ppi, 3 = 150 ppi, 4 = 96 ppi
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Auf „Nicht konfiguriert“ zurücksetzen
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\mailsettings"
Remove-ItemProperty -Path $key -Name 'oulookimagedpiindex' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Anpassung → Richtlinienverwaltung) enthält viele Benutzerrichtlinien der Microsoft 365 Apps – suchen nach Specify default quality of compression done on inlined images inserted in Outlook. Gilt auch auf nicht verwalteten Geräten und hat Vorrang vor GPO und Intune bei derselben Einstellung.

Erklärung von Microsoft

Diese Richtlinieneinstellung erlaubt es Ihnen, die Standardqualität der Komprimierung anzugeben, die in Outlook an Inlinebildern vorgenommen wird.

Wenn Sie diese Richtlinieneinstellung aktivieren, komprimiert Outlook die Inlinebilder in der Nachricht mit der angegebenen Qualität.

Wenn Sie diese Richtlinieneinstellung deaktivieren oder nicht konfigurieren, werden Inlinebilder mit der Standardqualität (220 dpi) komprimiert.

Hinweis: Diese Richtlinieneinstellung gilt nur für Abonnementversionen von Office wie Microsoft 365 Apps for Enterprise.
