PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\ms project\security' -ErrorAction SilentlyContinue | Select-Object 'level'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\ms project\security'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'level' -PropertyType DWord -Value 1 -Force | Out-Null   # options: 1 = Low (not recommended), 2 = Medium, 3 = High, 4 = Very High

Microsoft explanation

Specifies the level of security used when opening documents.

If you enable this policy setting, the security level you specified will be used when user open documents.

If you disable or do not configure this policy setting, the users default for this setting is followed.
