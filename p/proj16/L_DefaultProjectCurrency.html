PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\ms project\options\view' -ErrorAction SilentlyContinue | Select-Object 'currency'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\ms project\options\view'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'currency' -PropertyType String -Value 'AED' -Force | Out-Null   # options: AED = United Arab Emirates, Dirhams, AFA = Afghanistan, Afghanis, ALL = Albania, Leke, AMD = Armenia, Drams, AOA = Angola, Kwanza, ARS = Argentina, Pesos, AUD =

Default Project Currency (User)

Open in Intune Settings Catalog Viewer ↗

Microsoft explanation

Allows you to manage whether users can set the default currency type for their new project plans. If you enable this setting, the default currency type is enforced for all new project plans. If this setting is disabled or not configured, users can set the default currency type for new project plans.
