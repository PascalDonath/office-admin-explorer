Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\ms project\options\view' -ErrorAction SilentlyContinue | Select-Object 'default view'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\ms project\options\view'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'default view' -PropertyType String -Value 'Bar Rollup' -Force | Out-Null   # options: Bar Rollup = Bar Rollup, Calendar = Calendar, Descriptive Network Diagram = Descriptive Network Diagram, Detail Gantt = Detail Gantt, Gantt Chart = Gantt Chart,

Microsoft explanation

Specifies the view that Project displays at startup.

If you enable this setting, you can set the default view that is displayed at startup.

If you disable or do not configure this setting, the user's default setting is used.
