PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\ms project\options\view' -ErrorAction SilentlyContinue | Select-Object 'show scroll bars'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\ms project\options\view'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'show scroll bars' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled

Microsoft explanation

Displays scrollbars for views.

If you enable this setting, scrollbars are displayed in the views.

If you disable or do not configure this setting, the user's default setting is used.
