Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\ms project\options\calculation'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'auto calc' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled

Microsoft explanation

Specifies that calculations should be done automatically as soon as a change is made.

If you enable this setting, calculations will be made after every change to the project.

If you disable or do not configure this setting, the user's default setting is used.
