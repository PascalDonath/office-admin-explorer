PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\shared tools\proofing tools\tcsc translator' -ErrorAction SilentlyContinue | Select-Object 'translationtarget'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\shared tools\proofing tools\tcsc translator'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'translationtarget' -PropertyType DWord -Value 2052 -Force | Out-Null   # options: 2052 = Traditional Chinese to Simplified Chinese, 1028 = Simplified Chinese to Traditional Chinese

Microsoft explanation

This policy setting allows you to set the default translation direction for Chinese text.

If you enable this policy setting, the selected option will check the corresponding checkbox in the "Chinese Conversion" dialog. This dialog is found in the Review tab | "Convert with Options" button. This may only be visible when Chinese is enabled as an editing language.

If you disable or do not configure this policy setting, either translation direction may be set.
