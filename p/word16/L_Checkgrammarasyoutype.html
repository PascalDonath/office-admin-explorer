PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\word\options' -ErrorAction SilentlyContinue | Select-Object 'autogrammar'
Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\shared tools\proofing tools' -ErrorAction SilentlyContinue | Select-Object 'grammarwavyunderlinecolor'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\word\options'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'autogrammar' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
$key = 'HKCU:\Software\policies\microsoft\shared tools\proofing tools'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'grammarwavyunderlinecolor' -PropertyType DWord -Value 0 -Force | Out-Null   # options: 0 = Black, 255 = Blue, 128 = Dark Blue, 3368703 = Light Blue, 52479 = Sky Blue, 10079487 = Pale Blue, 6710937 = Blue Gray, 65280 = Green, 32768 = Dark Green, 13
