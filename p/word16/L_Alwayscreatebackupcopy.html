PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\word\options' -ErrorAction SilentlyContinue | Select-Object 'backupduringsave'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\word\options'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'backupduringsave' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
