PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\visio\application' -ErrorAction SilentlyContinue | Select-Object 'tipsdrawing', 'tipsdialogs', 'tipsrulers', 'tipsshapesheet'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\visio\application'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'tipsdrawing' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'tipsdialogs' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'tipsrulers' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'tipsshapesheet' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled

Microsoft explanation

This policy setting allows you to specify what ScreenTips appear in Visio to help you identify and use various features, including drawing window rulers, control handles, and ShapeSheet cells.

If you enable this policy setting, you may specify one or more other ScreenTips that will appear for:

- Drawing

- Dialogs

- Rulers

- ShapeSheet

If you disable or do not configure this policy setting, no ScreenTips will appear for the options listed above.
