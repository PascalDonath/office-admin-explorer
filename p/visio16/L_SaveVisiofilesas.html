PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\visio\application' -ErrorAction SilentlyContinue | Select-Object 'savefileformat'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\visio\application'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'savefileformat' -PropertyType DWord -Value 0 -Force | Out-Null   # options: 0 = Visio Document, 3 = Visio Macro-Enabled Document, 1 = Visio 2003-2016 Document
