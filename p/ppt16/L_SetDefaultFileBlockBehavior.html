PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\powerpoint\security\fileblock' -ErrorAction SilentlyContinue | Select-Object 'openinprotectedview'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\powerpoint\security\fileblock'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'openinprotectedview' -PropertyType DWord -Value 0 -Force | Out-Null   # options: 0 = Blocked files are not opened, 1 = Blocked files open in Protected View and can not be edited, 2 = Blocked files open in Protected View and can be edited

Microsoft explanation

This policy setting allows you to determine if users can open, view, or edit Word files.

If you enable this policy setting, you can set one of these options:

- Blocked files are not opened

- Blocked files open in Protected View and can not be edited

- Blocked files open in Protected View and can be edited

If you disable or do not configure this policy setting, users will be able to open blocked files, but not edit them.
