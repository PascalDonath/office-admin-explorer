PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\outlook\options\calendar' -ErrorAction SilentlyContinue | Select-Object 'show bothcal', 'alter calendar lang'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\outlook\options\calendar'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'show bothcal' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'alter calendar lang' -PropertyType DWord -Value 1054 -Force | Out-Null   # options: 1054 = Buddhist (Thai), 2052 = Chinese Lunar (Simplified Chinese), 1028 = Chinese Lunar (Traditional Chinese), 1025 = Gregorian (Arabic), 1033 = Gregorian (Engl
