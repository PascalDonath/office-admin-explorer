Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\outlook\pst'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'pstdisablegrow' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled

Microsoft explanation

This setting prevents users from adding any new content to PST files linked to their profiles.
