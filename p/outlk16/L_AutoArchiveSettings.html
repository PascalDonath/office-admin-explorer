PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\outlook\preferences' -ErrorAction SilentlyContinue | Select-Object 'doaging', 'everydays', 'promptforaging', 'deleteexpired', 'archiveold', 'archivemount', 'archiveperiod', 'archivegranularity', 'archivedelete'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\outlook\preferences'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'doaging' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'everydays' -PropertyType DWord -Value 1 -Force | Out-Null   # range 1–60
New-ItemProperty -Path $key -Name 'promptforaging' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'deleteexpired' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'archiveold' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'archivemount' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'archiveperiod' -PropertyType DWord -Value 1 -Force | Out-Null   # range 1–60
New-ItemProperty -Path $key -Name 'archivegranularity' -PropertyType DWord -Value 0 -Force | Out-Null   # options: 0 = Months, 1 = Weeks, 2 = Days
New-ItemProperty -Path $key -Name 'archivedelete' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled

Microsoft explanation

If you enable this policy setting, the options specified in the AutoArchive dialog box are disabled.
