Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\outlook\options\groups' -ErrorAction SilentlyContinue | Select-Object 'maxgroupssupported'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\outlook\options\groups'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'maxgroupssupported' -PropertyType DWord -Value 100 -Force | Out-Null   # range 100–1000

Microsoft explanation

This policy setting controls the maximum number of groups that are accessible through the Navigation Pane in Outlook for Windows.

If you enable this policy setting, only the number of groups set in the Groups Count will be shown in the Navigation Pane.

If you don’t enable this policy setting, the maximum number of groups displayed defaults to 1000.
