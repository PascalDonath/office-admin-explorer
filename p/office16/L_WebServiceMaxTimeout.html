Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\common\business data\limits\wcf\timeout' -ErrorAction SilentlyContinue | Select-Object 'max'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\common\business data\limits\wcf\timeout'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'max' -PropertyType DWord -Value 1 -Force | Out-Null   # range 1–75000000

Microsoft explanation

This policy setting allows you to specify the maximum timeout in milliseconds for the web service shim. This maximum value is enforced for applications that do not respect the default.

If you enable this policy setting, you may specify the maximum timeout in milliseconds for the web service shim.

If you disable or do not configure this policy setting, no maximum limit will be enforced.
