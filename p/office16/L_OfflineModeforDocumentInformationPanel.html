PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\common\documentinformationpanel' -ErrorAction SilentlyContinue | Select-Object 'msoridxdocsppcachedmodestatus'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\common\documentinformationpanel'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'msoridxdocsppcachedmodestatus' -PropertyType DWord -Value 0 -Force | Out-Null   # options: 0 = Disable Offline Mode, 1 = Enable Offline Mode, work offline now, 2 = Enable Offline Mode
