PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\common\internet' -ErrorAction SilentlyContinue | Select-Object 'alwayssaveindefaultencoding', 'encoding'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\common\internet'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'alwayssaveindefaultencoding' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled
New-ItemProperty -Path $key -Name 'encoding' -PropertyType DWord -Value 1256 -Force | Out-Null   # options: 1256 = Arabic Alphabet (Windows), 28594 = Baltic Alphabet (ISO), 1257 = Baltic Alphabet (Windows), 852 = Central European (DOS), 28592 = Central European Alphab
