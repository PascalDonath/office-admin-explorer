PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKLM:\Software\microsoft\internet explorer\main\featurecontrol\feature_http_username_password_disable' -ErrorAction SilentlyContinue | Select-Object 'groove.exe', 'excel.exe', 'mspub.exe', 'powerpnt.exe', 'pptview.exe', 'visio.exe', 'winproj.exe', 'winword.exe', 'outlook.exe', 'spdesign.exe', 'exprwd.exe', 'msaccess.exe', 'onenote.exe', 'mse7.exe'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'   # run elevated (HKLM)
$key = 'HKLM:\Software\microsoft\internet explorer\main\featurecontrol\feature_http_username_password_disable'
