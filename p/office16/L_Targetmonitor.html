PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\common\internet' -ErrorAction SilentlyContinue | Select-Object 'screensize', 'pixelsperinch'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\common\internet'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'screensize' -PropertyType String -Value '544x376' -Force | Out-Null   # options: 544x376 = 544 x 376, 640x480 = 640 x 480, 720x512 = 720 x 512, 800x600 = 800 x 600, 1024x768 = 1024 x 768, 1152x882 = 1152 x 882, 1152x900 = 1152 x 900, 1280x10
New-ItemProperty -Path $key -Name 'pixelsperinch' -PropertyType DWord -Value 72 -Force | Out-Null   # options: 72 = 72, 96 = 96, 120 = 120
