PowerShell

Check the current value (read-only):

Get-ItemProperty -Path 'HKCU:\Software\policies\microsoft\office\16.0\excel\options' -ErrorAction SilentlyContinue | Select-Object 'autoexpandlistrange'

Set it on a lab device (in production use Group Policy or Intune):

$ErrorActionPreference = 'Stop'
$key = 'HKCU:\Software\policies\microsoft\office\16.0\excel\options'
if (-not (Test-Path $key)) { New-Item -Path $key -Force | Out-Null }
New-ItemProperty -Path $key -Name 'autoexpandlistrange' -PropertyType DWord -Value 1 -Force | Out-Null   # Enabled

Microsoft explanation

When working in cells adjacent to a table (known as a "list" in previous versions of Excel), enabling this setting causes the adjacent row or column to become part of the table.
