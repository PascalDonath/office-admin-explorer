PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\microsoft\internet explorer\main\featurecontrol\feature_localmachine_lockdown"
foreach ($name in @('groove.exe', 'excel.exe', 'mspub.exe', 'powerpnt.exe', 'pptview.exe', 'visio.exe', 'winproj.exe', 'winword.exe', 'outlook.exe', 'spdesign.exe', 'exprwd.exe', 'msaccess.exe', 'onenote.exe', 'mse7.exe')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKLM values require an elevated PowerShell.
