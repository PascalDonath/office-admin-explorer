PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\internet"
foreach ($name in @('alwayssaveindefaultencoding', 'encoding')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKCU\Software\Policies is read-only for standard users. An elevated session writes to the admin's own HKCU – to set it for another signed-in user, change $root to Registry::HKEY_USERS\<SID>.

Enable

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\internet"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'alwayssaveindefaultencoding' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'encoding' -PropertyType DWord -Value 1256 -Force -ErrorAction Stop | Out-Null   # options: 1256 = Arabic Alphabet (Windows), 28594 = Baltic Alphabet (ISO), 1257 = Baltic Alphabet (Windows), 852 = Central European (DOS), 28592 = Central European Alphab
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Reset to Not configured
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\internet"
Remove-ItemProperty -Path $key -Name 'alwayssaveindefaultencoding', 'encoding' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Customization → Policy Management) offers many user policies of the Microsoft 365 Apps – search for Default or specific encoding. It also applies to unmanaged devices and wins over GPO and Intune for the same setting.

Microsoft explanation

When enabled, either default encoding or a specified encoding will be used.
