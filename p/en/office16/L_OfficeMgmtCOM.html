PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
foreach ($name in @('officemgmtcom')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKLM values require an elevated PowerShell.

Enable

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'officemgmtcom' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Disable
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\officeupdate"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'officemgmtcom' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

Microsoft explanation

This policy setting enables programmatic control of Microsoft 365 Apps for enterprise.

If you enable this policy setting, Microsoft Endpoint Configuration Manager or other application management solutions can manage Microsoft 365 Apps for enterprise. After applying the policy setting, you need to restart the Office Click-to-Run service.

If you disable or do not configure this policy setting, the Configuration Manager update workflow will not be able to manage Microsoft 365 Apps for enterprise. You will, however, be able to continue to use the Office Deployment Tool and Configuration Manager’s program and packages or applications deployment methods.

Note: This policy setting also applies to subscription versions of Project and Visio, which also are installed by using Click-to-Run.
