Microsoft explanation

This policy setting allows administrators to define which folders (local or network) Copilot cannot access.

If you enable this policy setting, Copilot is blocked from accessing the folders listed in this policy.

If you disable or don't configure this policy setting, only built-in protections for system/network locations apply.

For more information, see https://aka.ms/copilot-device-tools

Note: This policy setting only applies to subscription versions of Microsoft 365 Copilot on Windows and macOS desktop apps.
