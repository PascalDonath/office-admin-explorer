publishformat2 = Web Archive (*.mht) · 1 = Web Page (*.htm) · 0 = Default

Not configured = the value does not exist – the application default applies and users may change the setting.

PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\internet"
foreach ($name in @('publishformat')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKCU\Software\Policies is read-only for standard users. An elevated session writes to the admin's own HKCU – to set it for another signed-in user, change $root to Registry::HKEY_USERS\<SID>.

Enable

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\internet"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'publishformat' -PropertyType DWord -Value 2 -Force -ErrorAction Stop | Out-Null   # options: 2 = Web Archive (*.mht), 1 = Web Page (*.htm), 0 = Default
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Reset to Not configured
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\internet"
Remove-ItemProperty -Path $key -Name 'publishformat' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Customization → Policy Management) offers many user policies of the Microsoft 365 Apps – search for Default format for 'Publish'. It also applies to unmanaged devices and wins over GPO and Intune for the same setting.

Microsoft explanation

"Web Archive (*.mht)": The Publish command creates a Web Archive file. | "Web Page (*.htm)": The Publish command creates an HTML file. | "Default": The Publish command uses the default Web page format for publishing.
