Enable

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'suppressofficechannelselector' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Enabled
    $key = "$root\Software\policies\microsoft\office\16.0\common\officechannelexposure"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'insiderfast' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'firstreleasecurrent' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'current' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'monthlyenterprise' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'firstreleasedeferred' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'deferred' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }

Microsoft explanation

This policy setting controls whether the Update Channel option is shown under File > Account in an app, such as Word. This option allows users to select which update channel they want to receive updates from.

For more information about update channels, see https://go.microsoft.com/fwlink/p/?linkid=846105.

If you enable this policy setting, the Update Channel option is shown under File > Account. You need to select which update channels will be shown as options to the user.

Important:

- Users must be a local administrator on the device to change to a different update channel.

- Beta Channel is not a supported update channel. It should only be used in test environments and by a small group of select users, such as IT staff or application developers.

If you disable or don’t configure this policy setting, the Update Channel option is not shown under File > Account.

Notes:

- This policy setting only applies to subscription versions of Office, such as Microsoft 365 Apps for enterprise, and to subscription versions of Project and Visio.

- This policy setting takes precedence over the “Show the option for Microsoft 365 Insider” policy setting in cases where both policy settings are enabled.

- If you enable this policy setting, you shouldn’t enable and configure the “Target Version”, “Update Channel”, or “Update Path” policy settings under Computer Configuration\Policies\Administrative Templates\Microsoft Office 2016 (Machine)\Updates. If you do, those policy settings will take precedence. The Update Channel option will still appear under File > Account, but it will be disabled and the user won’t be able to select an update channel.
