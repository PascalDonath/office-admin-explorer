PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
foreach ($name in @('sharedcomputerlicensing')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKLM values require an elevated PowerShell.

Enable

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'sharedcomputerlicensing' -PropertyType DWord -Value 1 -Force -ErrorAction Stop | Out-Null   # Enabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Disable
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'sharedcomputerlicensing' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # Disabled
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Reset to Not configured
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\common\licensing"
Remove-ItemProperty -Path $key -Name 'sharedcomputerlicensing' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Microsoft explanation

This policy setting controls whether shared computer activation is used to activate the version of Office installed on the computer. By default, shared computer activation isn’t used for activation.

Shared computer activation is used only for situations where multiple users share the same computer. For example, when using Remote Desktop Services (RDS).

If you enable this policy setting, shared computer activation will be used to activate the version of Office installed on the computer.

If you do not configure this policy setting, shared computer activation will not be used to activate the version of Office installed on the computer unless you have enabled shared computer activation by using the Office Deployment Tool.

If you disable this policy setting, shared computer activation will not be used even if set using the Office Deployment Tool.

Note: This policy setting only applies to subscription plans that include Microsoft 365 Apps for enterprise, and to subscription versions of Project and Visio.
