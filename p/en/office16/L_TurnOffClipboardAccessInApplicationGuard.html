Registry

ValueData
HKCU\Software\policies\microsoft\office\16.0\common\security\applicationguard
clipboarddirection0 = Enable clipboard operation both directions (default) · 1 = Enable clipboard operation only from the host to the isolated session · 2 = Enable clipboard operation only from an isolated session to the host · 3 = Disable clipboard operation both directions
clipboardformats0 = Enable only text operations in the clipboard (default). · 1 = Enable only image operations in the clipboard. · 2 = Enable image and text operations in the clipboard.

Not configured = the value does not exist – the application default applies and users may change the setting.

PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\security\applicationguard"
foreach ($name in @('clipboarddirection', 'clipboardformats')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKCU\Software\Policies is read-only for standard users. An elevated session writes to the admin's own HKCU – to set it for another signed-in user, change $root to Registry::HKEY_USERS\<SID>.

Enable

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\common\security\applicationguard"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'clipboarddirection' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Enable clipboard operation both directions (default), 1 = Enable clipboard operation only from the host to the isolated session, 2 = Enable clipboard operat
    New-ItemProperty -Path $key -Name 'clipboardformats' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Enable only text operations in the clipboard (default)., 1 = Enable only image operations in the clipboard., 2 = Enable image and text operations in the cli
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Reset to Not configured
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\common\security\applicationguard"
Remove-ItemProperty -Path $key -Name 'clipboarddirection', 'clipboardformats' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Customization → Policy Management) offers many user policies of the Microsoft 365 Apps – search for Configure copy and paste from Office documents opened in Application Guard. It also applies to unmanaged devices and wins over GPO and Intune for the same setting.

Microsoft explanation

This policy setting allows you to control whether users can copy and paste content from Office to and from documents opened in Application Guard, as well as the allowed formats. This policy setting only applies to Word, Excel, and PowerPoint.

If you enable this policy setting, you must choose from the following behaviors:

- Enable clipboard functionality between the host and Application Guard (default).

- Disable clipboard functionality completely between the host and Application Guard.

- Enable the clipboard to copy content from Application Guard to the host.

- Enable the clipboard to copy content from the host to Application Guard.

Note: Application Guard only allows copying text and images and doesn’t allow copying of rich content.

Important: We recommend that you don't enable copying from the host to Application Guard. If you enable this functionality, a potentially compromised Application Guard session will have access to the host device’s clipboard and its content.

You can also choose the type of content that can be copied, by using the content options:

- Allows text copying (default).

- Allows image copying.

- Allows both text and image copying.

If you disable or don't configure this policy setting, users can copy and paste content to and from documents opened in Application Guard to other locations outside Application Guard.

Note: Application Guard only allows copying text and images and doesn’t allow copying of rich content.

Note: This policy setting only applies to Microsoft 365 Apps for enterprise.
