Not configured = the value does not exist – the application default applies and users may change the setting.

PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\lync"
foreach ($name in @('sipcompression')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKLM values require an elevated PowerShell.

Enable

# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

try {
    $key = "$root\Software\policies\microsoft\office\16.0\lync"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'sipcompression' -PropertyType DWord -Value 0 -Force -ErrorAction Stop | Out-Null   # options: 0 = Always disabled, 1 = Always enabled, 2 = Based on adaptor speed (default), 3 = Based on ping round-trip time
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Reset to Not configured
# --- Settings ---
$root = 'HKLM:'   # needs an elevated session

$key = "$root\Software\policies\microsoft\office\16.0\lync"
Remove-ItemProperty -Path $key -Name 'sipcompression' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Microsoft explanation

Defines when to turn on SIP compression. Default: Based on adaptor speed.

Setting this policy may cause an increase in sign-in time.
