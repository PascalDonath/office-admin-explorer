Microsoft explanation

This policy setting allows you to enable an external file format converter as the default for a particular file extension on a computer. To set this policy you need to specify the file extension (e.g. "odp") for Value Name and the external file format converter via the converter's classname (e.g. "TestConverter") for Value.

If you enable this policy setting for a particular file extension, the file format converter specified for that extension is used as the default converter for loading the files.

If you do not configure this policy setting for a particular file extension, Microsoft PowerPoint processes files with that extension in an application defined manner.

Note: This policy can only be specified once per file extension.
