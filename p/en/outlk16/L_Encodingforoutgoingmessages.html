PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mshtml\international"
foreach ($name in @('default_codepageout')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKCU\Software\Policies is read-only for standard users. An elevated session writes to the admin's own HKCU – to set it for another signed-in user, change $root to Registry::HKEY_USERS\<SID>.

Enable

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mshtml\international"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'default_codepageout' -PropertyType DWord -Value 28596 -Force -ErrorAction Stop | Out-Null   # options: 28596 = Arabic (ISO), 1256 = Arabic (Windows), 28594 = Baltic (ISO), 1257 = Baltic (Windows), 28592 = Central European (ISO), 1250 = Central European (Windows),
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Reset to Not configured
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\outlook\options\mshtml\international"
Remove-ItemProperty -Path $key -Name 'default_codepageout' -ErrorAction SilentlyContinue

Cloud Policy

Cloud Policy (config.office.com → Customization → Policy Management) offers many user policies of the Microsoft 365 Apps – search for Encoding for outgoing messages. It also applies to unmanaged devices and wins over GPO and Intune for the same setting.

Microsoft explanation

Sets the value in the option "Preferred encoding for outgoing messages".
