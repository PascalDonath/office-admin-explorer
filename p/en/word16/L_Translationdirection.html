Registry

ValueData
HKCU\Software\policies\microsoft\shared tools\proofing tools\tcsc translator
translationtarget2052 = Traditional Chinese to Simplified Chinese · 1028 = Simplified Chinese to Traditional Chinese

Not configured = the value does not exist – the application default applies and users may change the setting.

PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\shared tools\proofing tools\tcsc translator"
foreach ($name in @('translationtarget')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKCU\Software\Policies is read-only for standard users. An elevated session writes to the admin's own HKCU – to set it for another signed-in user, change $root to Registry::HKEY_USERS\<SID>.

Enable

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\shared tools\proofing tools\tcsc translator"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'translationtarget' -PropertyType DWord -Value 2052 -Force -ErrorAction Stop | Out-Null   # options: 2052 = Traditional Chinese to Simplified Chinese, 1028 = Simplified Chinese to Traditional Chinese
    'Done.'
}
catch { Write-Error "Failed: $($_.Exception.Message)" }
Reset to Not configured
# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\shared tools\proofing tools\tcsc translator"
Remove-ItemProperty -Path $key -Name 'translationtarget' -ErrorAction SilentlyContinue
'Policy values removed (Not configured).'

Cloud Policy

Cloud Policy (config.office.com → Customization → Policy Management) offers many user policies of the Microsoft 365 Apps – search for Translation direction. It also applies to unmanaged devices and wins over GPO and Intune for the same setting.

Microsoft explanation

This policy setting allows you to set the default translation direction for Chinese text.

If you enable this policy setting, the selected option will check the corresponding checkbox in the "Chinese Conversion" dialog. This dialog is found in the Review tab | "Convert with Options" button. This may only be visible when Chinese is enabled as an editing language.

If you disable or do not configure this policy setting, either translation direction may be set.
