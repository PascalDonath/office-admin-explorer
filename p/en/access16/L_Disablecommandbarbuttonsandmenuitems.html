PowerShell

Check the current value (read-only)

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

$key = "$root\Software\policies\microsoft\office\16.0\access\disabledcmdbaritemscheckboxes"
foreach ($name in @('sendtomailrecipient', 'toolssecuritysetpwd', 'toolssecurityperms', 'toolssecurityaccts', 'toolssecuritysecwiz', 'toolssecurityencrypt', 'toolsmacrovbe', 'accrunmacro', 'toolsmacroconvertmacros', 'toolsmacrocreateshortcutmenu', 'addinsmenuicon')) {
    try   { '{0} = {1}' -f $name, (Get-ItemPropertyValue -Path $key -Name $name -ErrorAction Stop) }
    catch { '{0}: not configured' -f $name }
}

Admin rights needed: HKCU\Software\Policies is read-only for standard users. An elevated session writes to the admin's own HKCU – to set it for another signed-in user, change $root to Registry::HKEY_USERS\<SID>.

Enable

# --- Settings ---
$root = 'HKCU:'   # other signed-in user (elevated): 'Registry::HKEY_USERS\<SID>'

try {
    $key = "$root\Software\policies\microsoft\office\16.0\access\disabledcmdbaritemscheckboxes"
    if (-not (Test-Path $key)) { New-Item -Path $key -Force -ErrorAction Stop | Out-Null }
    New-ItemProperty -Path $key -Name 'sendtomailrecipient' -PropertyType DWord -Value 2188 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolssecuritysetpwd' -PropertyType DWord -Value 1814 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolssecurityperms' -PropertyType DWord -Value 572 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolssecurityaccts' -PropertyType DWord -Value 1816 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolssecuritysecwiz' -PropertyType DWord -Value 1815 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolssecurityencrypt' -PropertyType DWord -Value 2074 -Force -ErrorAction Stop | Out-Null   # Enabled
    New-ItemProperty -Path $key -Name 'toolsmacrovbe' -PropertyType DWord -Value 1695 -Force -ErrorAction Stop | Out-Null   # Enabled

Cloud Policy

Cloud Policy (config.office.com → Customization → Policy Management) offers many user policies of the Microsoft 365 Apps – search for Disable predefined commands. It also applies to unmanaged devices and wins over GPO and Intune for the same setting.

Microsoft explanation

This policy setting allows you to disable specific command bar buttons and menu items in the specified applications.

If you enable this policy setting you can disable specific command bar buttons and menu items in the user interface for the selected application. The predefined list of command bar buttons and menu items you can disable becomes available to you when you enable this policy setting.

If you disable or do not configure this policy setting, the predefined list of command bar buttons and menu items are enabled for the application.
